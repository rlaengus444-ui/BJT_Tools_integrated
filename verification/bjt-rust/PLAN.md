# BJT 선택적 Rust 커널 계획

기준은 기존 최적화가 적용된 BJT 소스 SHA-256 `727b6db3b46c1f0d13696d93f7ba9ef039facd87c1722fee1613b5fe32a08d72`이다. 원본과 이전 검증 산출물은 보존한다. 구현 전 Sol Max 설계 검토에 따라 Python 대체 경로를 유지하는 선택적 native C ABI를 단계적으로 평가한다.

1단계는 정확한 edge 정렬/계수 커널을 대상으로 한다. ABI 버전과 레코드 배치 검증, 잘못된 입력 처리, 예외 격리, fallback, 정렬과 접촉 분류 동등성을 검사하고 실제 native 실행과 출처를 기록한다. 기존 Python 동작과 출력, 취소 및 제한을 유지해야 한다. 구현 후 독립 Sol Max 검토와 관련 회귀 검증이 필요하다.

2단계 rectangle-to-record 출력 커널은 1단계의 정확성과 측정 결과를 검토한 뒤에만 별도 판단한다. 현재 성능 향상을 보장하거나 측정 결과를 주장하지 않는다. Windows 패키징, GUI 및 실제 장비는 별도 검증 대상이다. 빌드 스크립트는 로컬 선택적 라이브러리만 생성하며 릴리스 빌드, 배포 또는 업로드를 수행하지 않는다.

1단계 edge 정렬/계수와 2단계 기존 q의 레코드 packing 구현 및 최종 비교가 완료되었다. 최종 측정과 양쪽 파이프라인 증거는 [README.md](README.md)를 참조한다. 독립 검토 결과는 별도로 기록한다. 빌드 준비 단계는 호스트에 맞는 선택적 라이브러리가 있을 때만 포함하며, 없으면 Python fallback을 사용한다. EXE 빌드와 Windows 실행 검증은 수행하지 않았다.
