# IR 통합 회귀 검사

`upstream_tests/`는 IR_feedback 커밋 `2372c29602a9538f78593699c5e34c0485373524`의
원본 테스트 58개와 시험 보조 자료를 바이트 그대로 보존한다. 해시는
`upstream-tests-manifest.json`에 기록되어 있다.

```bash
python verification/ir-integration/run_upstream_tests.py --output /별도경로/ir-upstream-tests.json
```

별도 시험 프로세스에서 실제 `suite/ir_feedback` 패키지를 불러와 원본 시험이
사용하는 평면 모듈 이름에만 임시 별칭을 붙인다. 제품의 모듈 검색 경로나 모듈
이름은 변경하지 않는다. `mock.patch`도 같은 실제 제품 모듈 객체에 적용된다.

원본 시험의 `__file__` 기반 소스·리소스 조회는 임시 폴더에서 수행한다. 이 폴더에는
통합 제품의 현재 소스·DLL·PowerShell·JSON·템플릿을 복사하고 SHA-256 일치를
확인한다. 과거 온도 수치 JSON 두 개만 보존된 원본 시험 자료에서 가져온다.
제품 모듈의 실제 `__file__`과 실행 코드는 계속 `suite/ir_feedback`를 가리킨다.
기존 IR 저장소나 사용자 파일은 필요하지 않다.

원본 기준은 572개 시험이며 실패·오류 또는 예상과 다른 수집 개수가 있으면
종료 코드가 1이다. JSON에는 실제 통과 여부와 실행 개수, 생략 사유, 오류,
사용한 제품 파일 해시를 남긴다. 원본 시험은 수정하지 않으므로 Linux에서 표시 서버가 없거나 Windows 전용 시험을 실행하면
일부 항목은 생략, 일부 항목은 오류/실패로 남는다. 해당 원인을 별도로 기록하며 통과로 바꾸지 않는다. Windows GUI 실행 및
Excel COM의 실제 연동은 별도의 검증이며 이 시험만으로 완료했다고 주장하지 않는다.

시험은 임시 CSV, 가상 제어기, 소유한 모의 프로세스만 사용한다. 실제 장비를
검색하거나 히터 출력을 변경하는 시험은 실행하지 않는다.

## 통합 범위 · 1.10.0

통합판 기본 브랜치 a1c78e2(최신 배포 1.9.2)에 IR_feedback 2372c296의 런타임을 격리 패키지로 추가했습니다. 기존 12개 도구의 원본 소스 해시는 유지합니다. 실제 이미지 회복제어 원본은 11,523,470바이트이며 SHA-256은 `eb34cd39d364011015bee1a03cc1c024a1bb41911df35ed5aeac41b299941c20`입니다. 기존 참고용 템플릿을 원본 대신 사용하지 않습니다.

원본 대비 로컬 import를 패키지 상대 import로 바꿨습니다. 추가 변경은 선택/종료용 GUI 훅, ExcelGroupFence의 읽기 전용 정리 조회, WorkbookSpec의 선택적 정확 바이트 해시 확인입니다. 계산식·CSV 작업 식별·층 유효성·저장 로직은 유지합니다. 이력은 `suite/ir_feedback/provenance.json`에 기록합니다.

실제 Excel COM과 센서/PLC/램프는 미검증입니다. 최종 제어 알고리즘 승인과 장비 적용은 보류합니다. 독립 설계 검토는 `sol-design-review.json`에 기록하며 구현·패키지 검토와 구분합니다.
