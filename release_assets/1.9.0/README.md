# 1.9.0 소스 배포 파일

`BJT_통합프로그램_1.9.0_전체소스.zip`을 전체 압축 해제하고 `BJT_통합프로그램.py`를 PyCharm에서 실행하세요. Python 3.12 x64를 선택합니다. 첫 실행에는 고정 패키지 설치가 필요합니다. 같은 창에 기존 도구와 모델 자동 배치가 함께 열립니다. 내장 정책은 추론 전용입니다.

단일 `.py`만 받으려면 저장소 루트의 `BJT_통합프로그램.py`를 사용하세요. 단독 배치 참고본은 `standalone/`에 있습니다. 소스와 아카이브 무결성은 `source-release-verification.json`, 실행 검증과 알려진 제한은 `../../verification/packing-policy/`에 기록했습니다.

이 파일은 소스 ZIP입니다. 실제 Windows EXE 검증 결과를 대신하지 않습니다.
