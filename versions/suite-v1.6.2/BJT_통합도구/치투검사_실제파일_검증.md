검사용 복사본에서만 기존 삼각형을 원래의 내부 정점으로 분할했다. 각 분할은 기존 방향의 표면을 정확히 나누며, 제거한 면적 0 연결면은 남아 있는 모서리 위에 완전히 포함됨을 원래 좌표의 정확한 유리수 연산으로 확인했다. 원본 정점 좌표와 경계는 비트 단위로 동일하다. 구멍을 추정해서 채우거나 좌표를 허용오차로 합치지 않았다.

정리 후 기존의 엄격한 닫힘·일관된 면 방향·양의 부피 검사를 다시 수행하여 두 모델 모두 통과했다. 일반 유효 메쉬는 이 정리 경로를 실행하지 않는다. 열린 메쉬·비다양체·반복 정점 번호·정리 범위 초과·정리 후 재검증 실패는 계속 판정 불가다.

JSON의 각 대상 `objects`에는 원래 오류인 `source_errors`와 정리 감사 정보인 `normalization`을 기록한다. `coordinates_unchanged`, `exact_surface_union_preserved`, `exact_oriented_surface_chain_preserved`와 연결면별 분할 내역을 보존한다. GUI·명령줄·3D HTML에는 원본 형상을 유지한 정리와 대상 2개를 안내한다.

## 독립 기준과 원본 프로젝트 판정

별도의 전체 정밀 교차 시험에서 방향 보존 삼각형 분할 증거와 독립 기준을 대조했다. 두 카메라가 포함된 **95쌍**의 최대 거리 차이는 **0.0 mm**, 최대 교차 부피 차이는 **0.0 mm³**였다. 원본 파일과 호출자가 가진 원래 메쉬가 바뀌지 않았음도 확인했다.

일반 검사에서는 새롭게 판정 가능한 카메라 관련 쌍의 충분한 간격을 거리 하한으로 확인할 수 있다. 요구 간격 0/1 mm의 경우 이 95쌍 중 **4쌍은 정밀 거리**, **91쌍은 보장된 하한(≥)**으로 판정한다. 기존부터 유효했던 소규모 모델 사이의 쌍은 기존처럼 정확한 거리를 계산한다. 전체 최소 간격과 모든 간격 미달·접촉·겹침은 정밀 계산하므로, 전체 정밀 교차 시험의 95쌍 검증과 일반 검사의 출력 거리 범위를 구분한다.

| 요구 최소 간격 | 전체 판정 완료 | 결과 |
| ---: | --- | --- |
| 0 mm | 예 | 49개 오브젝트, 1,176쌍 PASS |
| 1 mm | 예 | 49개 오브젝트, 1,176쌍 PASS |
| 1.5 mm | 예 | [5] ↔ [6] 한 쌍 간격 미달 |
| 2 mm | 예 | [1]↔[4], [2]↔[4], [5]↔[6], [5]↔[7] 네 쌍 간격 미달 |

가장 가까운 쌍 [5] ↔ [6]의 거리는 **1.4999923706054688 mm**다. 1.5 mm보다 작은 차이는 약 0.0000076294 mm로, 기본 거리 허용오차 0.000001 mm보다 크므로 요구 1.5 mm에서는 Fail이다. 이 파일에서는 겹침이나 표면 접촉을 발견하지 않았다.

이 내용은 실제 소스의 형상·판정 교차 검증이다. 1.6.2의 성능은 동일 조건의 소스 ABBA 반복과 최종 EXE 실행 측정으로 별도 확인하며, 읽기 단계만의 중간 후보 수치나 아래 이전판 시간을 최종 성능으로 사용하지 않는다. 최종 측정 범위와 결과는 배포 검증 기록을 함께 확인한다.
