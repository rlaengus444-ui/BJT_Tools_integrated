1. 제품 개요와 작업 범위

번호 복제·누락 검사는 한 원본 파일을 지정한 번호 이름으로 여러 개 복제하는 작업과, 한 폴더의 파일명에 있는 선행 숫자로 누락 번호를 찾는 작업을 제공합니다. 빈 슬라이스 파일을 여러 번호로 준비하거나, 내보낸 파일의 번호가 예상 범위를 채우는지 확인할 때 사용합니다.

기능입력과 결과검사 범위
번호 복제원본 파일 하나 → Min부터 Max까지 번호 파일 생성원본 확장자와 파일 바이트를 그대로 복사
Missing No. 누락 검사대상 폴더와 예상 번호 범위 → 누락·중복 등 번호 현황파일명과 확장자만 사용하며 이미지 픽셀을 해독하지 않음
이미지 자체의 일치성 확인통합 프로그램의 ‘슬라이싱 일치성 검사’ 사용픽셀·해상도·비트 수·실제 형식 등은 해당 탭에서 확인
확인 사항

번호가 모두 존재한다는 결과는 파일 내용이 정상이라는 뜻이 아닙니다. 같은 번호가 적힌 잘못된 그림이나 손상 파일도 이름만으로는 구별할 수 없습니다. 실제 이미지 검증이 필요하면 별도의 일치성 검사를 수행하세요.

2. 빠른 시작 — blank.png를 10~20번으로 복제

  1. 통합 프로그램에서 ‘번호 복제·누락 검사’ 탭을 열고 ‘번호 파일 복제’를 선택합니다. ‘사용설명서’ 또는 메인 창의 F1로 이 설명서를 다시 열 수 있습니다.
  2. 원본 파일에 blank.png를 선택합니다. 이 파일의 실제 내용과 복제에 사용할 확장자를 먼저 확인합니다.
  3. 출력 폴더를 선택합니다. 출력 폴더를 비워 두면 원본 파일이 있는 폴더를 사용합니다. 별도 빈 폴더를 선택하면 결과를 구분하기 쉽습니다.
  4. Min에 10, Max에 20을 입력합니다. 양 끝을 포함하여 11개 번호가 처리 대상입니다.
  5. 기존 파일 처리 정책을 확인합니다. 기본 ‘건너뛰기’를 유지하면 같은 이름의 기존 파일을 보존합니다.
  6. ‘복제 시작’을 누르고 진행 상태와 로그를 확인합니다. 완료 후 생성·건너뜀·오류 수를 구분해 읽습니다.
  7. 출력 폴더를 열어 10.png~20.png가 준비되었는지 확인합니다. 이미 있던 파일을 건너뛰었다면 해당 파일은 원본 blank.png로 갱신되지 않았습니다.
참고

이 예시는 출력 폴더에 충돌 파일이 없을 때 11개가 생성됩니다. 중지·오류·기존 파일·원본과 같은 경로가 있으면 실제 생성 수는 처리 번호 수보다 적을 수 있습니다.

3. 원본·출력 폴더·번호 범위

항목의미확인할 내용
원본 파일반복 복사할 파일 한 개작업이 끝날 때까지 수정·삭제하거나 다른 파일로 교체하지 않기
출력 폴더번호 파일을 저장할 위치공란이면 원본의 부모 폴더. 쓰기 권한과 여유 공간 확인
Min(포함) / Max(포함)시작 번호 / 끝 번호정수이며 Min≤Max. 양 끝 포함. 처리 번호 수 = Max − Min + 1
파일명번호 + 원본 확장자blank.png, Min 10 → 10.png. 원본 이름의 접두사는 복사하지 않음
파일 내용원본 전체 바이트 그대로 복사잘라내기·리사이즈·회전·명도 변경·압축 변환을 하지 않음

복제 원본은 일반 파일이며 이미지 형식으로 제한하지 않습니다. 원본이 .TIFF이면 결과도 대소문자를 유지한 .TIFF이며, 확장자를 바꾸어 다른 형식으로 변환하지 않습니다. 원본 이름의 마지막 확장자를 사용하고 확장자가 없으면 번호만으로 저장합니다. 숫자는 기본 숫자 이름으로 작성하므로 00010.png처럼 자릿수를 채우는 입력은 제공하지 않습니다. 원본 확장자와 출력 이름을 시작 전에 확인하세요.

참고

복제 범위에는 음수도 입력할 수 있습니다. 예를 들어 −1번 결과는 -1.png가 되지만, Missing No. 검사는 맨 앞 숫자만 읽으므로 이 파일은 ‘번호 없는 파일’로 분류됩니다. 누락 검사와 함께 사용할 번호 파일은 목적에 맞는 0 이상의 번호 범위를 정하세요.

참고

복제는 같은 파일 내용을 여러 번호에 배치하는 기능입니다. 한 이미지 안에 여러 제품을 배치하거나 슬라이스의 Z 높이에 맞는 서로 다른 그림을 생성하지 않습니다. 빈 레이어가 필요한 범위에 사용할지 여부는 실제 공정 조건으로 판단합니다.

목차와 처음으로 ↑

4. 기존 파일 처리와 원본 보호

정책15.png가 이미 있을 때기존 파일에 미치는 영향
건너뛰기 (기본)15번을 건너뛰고 다음 번호로 진행기존 15.png 유지. 기존 파일이 원본과 같은지는 검사하지 않음
덮어쓰기복사가 끝난 새 파일로 15.png 교체이전 내용이 바뀜. 자동 백업·자동 복구 없음
이름 바꿔 저장15_1.png, 15_2.png처럼 비어 있는 이름 탐색기존 15.png 보존. 같은 선행 번호의 파일이 늘어날 수 있음
확인 사항

‘덮어쓰기’로 교체한 기존 파일에는 자동 백업이 생기지 않습니다. 이전 내용이 필요하면 작업 전에 다른 폴더에 직접 보관하세요. 중지하거나 다시 실행해도 이미 덮어쓴 파일이 자동으로 원래대로 돌아오지 않습니다.

대상 경로가 원본 파일 자신과 같으면 건너뛰기·덮어쓰기 정책에서도 원본을 덮어쓰지 않고 건너뜁니다. 예를 들어 원본이 10.png이고 출력이 같은 폴더, 범위가 10~20이면 10.png 자체는 유지됩니다. 이름 바꾸기 정책에서는 원본 10.png를 보존하면서 10_1.png 등 별도 이름에 복사할 수 있습니다. 로그와 최종 집계에서 실제 처리를 확인합니다.

각 결과는 먼저 임시 파일에 끝까지 복사한 뒤 최종 이름으로 반영합니다. 중지·오류로 끝나지 못한 임시 복사를 완성된 번호 파일로 남기지 않도록 처리하며, 덮어쓰기 대상도 복사 완료 전에는 기존 내용이 유지됩니다. 이 보호는 파일 한 개 단위이며 전체 범위를 한 번에 되돌리는 거래나 백업 기능은 아닙니다.

5. 빠른 시작 — 예상 1~5번의 누락 찾기

  1. ‘Missing No. 검사’를 선택합니다.
  2. 검사할 파일들이 직접 들어 있는 대상 폴더를 선택합니다. 하위 폴더는 자동으로 내려가 검사하지 않습니다.
  3. 확장자 필터를 정합니다. PNG 레이어만 확인하려면 .png를 선택합니다.
  4. 예상 범위 Min에 1, Max에 5를 입력합니다. 실제로 존재하는 파일의 최솟값·최댓값이 아니라 작업에서 기대하는 전체 범위를 입력합니다.
  5. ‘누락 번호 검사’를 누른 뒤 결과에서 누락 번호와 중복 번호를 확인합니다.
  6. 1.png, 2.png, 4.png만 있다면 누락은 3과 5입니다. 누락 파일이 필요한지 원본 작업에서 확인한 후 다시 내보내거나 복사하고 재검사합니다.

예상 범위의 Min과 Max를 모두 비우면 파일명 현황만 조사합니다. 이때 누락 번호 검사는 수행하지 않으며, 존재하는 최솟값·최댓값을 기대 범위로 자동 추정하지 않습니다. 한쪽만 입력하면 오류가 나므로 누락을 확인하려면 양쪽을 함께 입력하세요.

확인 사항

번호가 빠졌다는 이유만으로 같은 그림을 임의로 복제해 채우지 마세요. 모든 층이 같은 내용이어야 하는 작업인지, 해당 층에 다른 단면이 필요한지 먼저 확인해야 합니다.

목차와 처음으로 ↑

6. 선행 숫자와 확장자 필터 규칙

번호는 파일명 맨 앞에서 연속되는 숫자를 읽습니다. 숫자가 끝난 뒤의 접미사는 번호에 포함하지 않습니다. 파일명 어디에나 있는 마지막 숫자를 읽는 다른 도구의 규칙과 혼동하지 마세요.

파일명 예시인식 번호해석
1.png / 001.png둘 다 1같은 필터에 함께 포함되면 번호 1의 중복
15_1.png / 15-copy.png둘 다 15접미사는 번호를 별도로 만들지 않음
layer15.png없음첫 글자가 숫자가 아니므로 번호 없는 파일
preview.png없음이미지여도 선행 번호가 없으면 누락 범위를 채우지 않음
-1.png / +1.png없음부호로 시작하므로 선행 숫자 규칙에 맞지 않음
3.png / 3.tiff둘 다 3두 확장자를 모두 검사하는 필터라면 같은 번호로 집계
확장자 필터대상 범위
(전체) — 기본값폴더 바로 아래의 일반 파일 전체. 이미지 외 파일도 포함
.jpg / .jpeg / .png / .bmp / .tif / .tiff / .webp선택한 확장자 하나의 파일. 파일명 확장자로 선별하며 내용 형식을 해독하지 않음

검사는 지정 폴더 바로 아래의 대상 파일만 읽습니다. 이미지 내부에 기록된 층 번호, ZIP 내부 항목, 하위 폴더 이름은 이 누락 검사의 번호 근거가 아닙니다. 확장자 필터를 바꾸면 대상 파일과 중복·누락 결과도 달라질 수 있습니다. 예를 들어 ‘(전체)’에서는 1.txt도 번호 1을 채울 수 있으므로 PNG 레이어의 누락을 확인할 때는 .png 필터를 사용하세요.

7. 누락·중복·범위 밖·번호 없는 파일

분류의미확인할 작업
누락 번호예상 Min~Max 안에 해당 번호의 대상 파일이 없음선택 폴더·필터·기대 범위를 확인한 뒤 원본에서 복원
중복 번호같은 선행 번호를 가진 대상 파일이 두 개 이상001.png와 1.png, 15.png와 15_1.png 등 실제 파일명을 확인
범위 밖 번호대상 파일 번호가 예상 범위보다 작거나 큼다른 작업이나 추가 레이어가 섞였는지 확인
번호 없는 파일대상 파일 이름이 숫자로 시작하지 않음미리보기·설명 파일인지, 이름 규칙이 다른 레이어인지 확인

중복 파일이 여러 개 있어도 같은 번호의 존재 여부는 한 번만 채웁니다. 1.png와 001.png 두 개가 있다고 해서 1번과 2번이 모두 있는 것은 아닙니다. 범위 밖 파일이나 번호 없는 파일도 예상 범위의 누락을 대신 채우지 않습니다. 링크 파일은 따라 읽지 않고 ‘링크 제외’로 별도 기록합니다.

확인 사항

중지·읽기 오류가 있는 검사는 일부 파일만 읽은 상태이므로 전체 누락 번호를 확정하지 않습니다. JSON의 missing_checked가 false이고 missing_count가 null인 상태를 ‘누락 0개’로 해석하지 마세요. Min/Max를 모두 비운 현황 조사도 누락 번호는 판정하지 않습니다.

참고

누락 검사는 파일명을 읽는 작업이므로 이미지 손상·해상도·DPI·비트 수·압축·픽셀 위치를 검사하지 않습니다. 복제한 파일과 기존 파일의 내용이 같은지 확인하려면 ‘슬라이싱 일치성 검사’에서 원본 묶음과 결과를 비교하세요.

8. 작업 예시와 재실행 결과

9. 진행 상태·중지·통합 창 종료

  1. 시작 후 현재 작업 상태와 진행 막대, 로그를 확인합니다. 복제의 진행 수는 처리한 번호 수이며 새로 생성한 파일 수와 다를 수 있습니다. 누락 검사의 움직이는 진행 막대는 작업 중임을 나타내며 남은 비율을 뜻하지 않습니다.
  2. 중단하려면 해당 화면의 중지 버튼을 누릅니다. 통합 창 상단의 ‘현재 작업 중단’도 이 도구 탭을 선택한 상태에서 사용할 수 있습니다.
  3. 중지 요청이 처리되고 임시 파일 정리가 끝날 때까지 기다립니다. 이미 완료한 복제 파일은 그대로 남습니다.
  4. 중지·오류 결과를 확인하고 출력 폴더와 집계를 검토한 뒤 재실행 여부를 정합니다.
  5. 통합 창을 닫을 때 진행 중 작업이 있으면 중단 확인과 정리 완료를 기다립니다.
확인 사항

중지는 전체 작업의 되돌리기가 아닙니다. 이미 생성하거나 덮어쓴 파일은 자동 삭제·복구되지 않습니다. 작업 전 백업과 완료 후 결과 확인은 별도로 수행해야 합니다.

복제는 처음 발생한 쓰기 오류에서 중단하여 ‘오류 · 부분 결과’로 안내합니다. 정상 처리한 앞부분은 유지되므로 오류 경로와 집계를 확인하세요. 다른 통합 탭으로 이동해도 진행 중인 작업은 계속될 수 있습니다. 상단 중단 버튼은 현재 선택한 도구에 전달되므로 이 도구로 돌아온 뒤 사용합니다. 원본과 출력 경로를 외부 프로그램에서 동시에 바꾸지 않도록 합니다.

10. 로그와 결과 보관

작업 전 입력 원본·출력 경로·Min/Max·충돌 정책을 확인하고, 작업 후에는 완료·중지·오류 상태와 생성·건너뜀·오류 집계를 구분해 읽습니다. ‘처리 11개’가 항상 ‘새 파일 11개 생성’을 뜻하지는 않습니다.

  1. 결과를 보관하려면 ‘결과 저장(JSON)’을 눌러 보고서의 저장 경로를 선택합니다.
  2. 화면의 진행·작업 메시지는 ‘로그 저장(TXT)’으로 별도 보관합니다.
  3. 중지·오류가 있는 작업은 파일명에도 ‘부분’ 또는 ‘중지’를 구분하고, JSON의 완료 상태와 집계를 함께 확인합니다.
  4. 복제 결과를 확인하려면 ‘출력 폴더 열기’를 사용합니다. 파일 생성 위치가 의도한 곳인지 확인합니다.

누락·중복 파일명·범위 밖·번호 없는 파일파일 수와 실제 번호 현황을 구분하여 정리

새 작업을 시작하면 화면 로그와 현재 보고서가 초기화되므로 보관할 결과는 먼저 저장합니다. 누락 검사는 대상 파일을 수정하지 않습니다. 결과가 나타난 뒤 파일을 추가·이름 변경·삭제했다면 이전 결과는 그 변경을 자동으로 반영한 것이 아니므로 다시 검사해야 합니다. 복제 로그를 보관해도 덮어쓰기 전 파일 내용의 백업이 되는 것은 아닙니다.

11. 처리 한계와 문제 해결

증상원인 확인조치
시작할 수 없음원본·대상 폴더·정수 범위·Min≤Max 조건오류 안내에 따라 입력을 수정
출력이 원본 옆에 생성됨출력 폴더가 공란별도 출력 폴더를 선택하고 범위를 다시 확인
처리는 끝났는데 생성 수가 적음건너뛰기·원본 같은 경로·중지·오류로그와 최종 집계 확인
기존 파일 내용이 바뀌지 않음기본 건너뛰기 정책보존이 의도한 결과인지 확인. 갱신이 필요하면 백업 후 정책 결정
기존 파일이 새 내용으로 바뀜덮어쓰기 정책자동 복구 없음. 작업 전 보관본에서 수동 복원
_1, _2 파일이 늘어남이름 바꾸기 정책으로 반복 실행파일명과 선행 번호 중복을 확인하고 필요한 파일을 구분
layer001.png가 번호 없음번호는 파일명 맨 앞 숫자만 인식원본 명명 규칙과 검사 목적 확인
다른 폴더의 파일이 결과에 안 나옴하위 폴더를 검사하지 않음해당 파일이 직접 들어 있는 폴더를 지정
파일이 있는데 누락으로 표시됨확장자 필터·파일명·예상 범위 차이이름 시작 숫자와 선택 필터 확인
복제 오류·출력 실패쓰기 권한·디스크 여유·잠긴 파일·원본 변경오류 경로와 메시지 확인 후 조건을 해결하고 재실행
링크 경로 또는 폴더 링크 거부원본 심볼릭 링크, 출력 폴더의 심볼릭 링크·정션 등실제 원본 파일과 실제 출력 폴더를 직접 지정
중단 후 일부 번호 파일이 남음완료한 파일은 유지되는 정상 동작남은 파일을 확인하고 재실행 정책 결정

기존 출력 대상이 링크인 경우에도 실제 연결 대상을 따라 덮어쓰지 않도록 제한합니다. 건너뛰기는 보존하고 이름 바꾸기는 다른 이름을 찾지만, 해당 링크에 대한 덮어쓰기는 거부할 수 있습니다. 일반 파일과 실제 폴더를 사용하고 처리 메시지를 확인하세요.

복제에 필요한 공간은 대략 원본 파일 크기 × 새로 만들 파일 수이며, 처리 중인 임시 파일과 기존 파일이 함께 존재할 여유도 필요합니다. 안전한 새 파일 반영에 필요한 기능을 출력 파일시스템이 지원하지 않으면 오류로 중단될 수 있으므로 다른 실제 로컬 출력 폴더를 확인하세요. 많은 번호나 큰 파일을 처리하면 저장장치 속도가 진행 시간에 영향을 줍니다. 누락 검사는 파일명을 읽으므로 이미지 크기를 줄이거나 DPI를 변경할 필요가 없습니다.

참고

큰 범위는 누락 번호를 하나씩 나열하지 않고 연속 범위로 보관합니다. 복제 상세의 10,000건 제한과 화면 목록 제한은 처리 개수 제한이 아니며, 집계와 상세 목록 길이를 구분해야 합니다. 누락 검사는 실제 파일 이름 목록을 메모리에 보관하므로 파일 수가 아주 많은 폴더에서는 시간과 메모리가 더 필요합니다.

12. 용어와 작업 완료 확인

용어설명
포함 범위Min과 Max를 모두 처리하는 범위. 10~20은 11개 번호
충돌저장하려는 최종 이름의 파일이 이미 존재하는 상태
선행 숫자파일명 맨 앞의 연속 숫자. 015_copy.png의 번호는 15
원자적 반영임시 복사가 완료된 뒤 한 파일을 최종 경로로 교체하는 처리
누락 번호선택한 필터의 파일명 중 예상 범위에 없는 번호
중복 번호파일명은 달라도 같은 선행 번호를 공유하는 항목
  • 복제할 원본과 실제로 필요한 번호 범위가 맞다.
  • 출력 위치와 기존 파일 정책을 확인했으며, 덮어쓰기 전에 필요한 백업을 직접 만들었다.
  • 완료·중지·오류와 생성·건너뜀 집계를 구분했다.
  • 누락 검사에서 올바른 폴더·확장자·예상 범위를 사용했다.
  • 중복과 번호 없는 파일을 확인했으며 파일 수만으로 연속 번호를 판단하지 않았다.
  • 번호 검사와 이미지 내용 검증을 구분하고 필요하면 일치성 검사를 추가했다.
  • 작업 조건과 결과를 보관했다.
