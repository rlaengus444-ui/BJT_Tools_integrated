1. 기능과 원본 수식의 적용 범위

시퀀스별 Z값은 M1 Tools의 ‘M1 Z축’ 시트에 있던 계산을 통합 프로그램에서 수행합니다. 초기 Z, 이동/피딩(Trinity) 하강값, 리코팅 상승값을 입력하면 지정한 레이어의 세 위치를 조회하거나 연속 레이어 전체표를 CSV로 저장할 수 있습니다. 원본 Excel 파일을 열거나 VBA를 실행할 필요가 없습니다.

기능입력과 결과기본값
단일 레이어 조회레이어 하나의 프린팅·Trinity·리코팅 Z조회 레이어 1
전체표지정 범위를 포함하여 계산, 페이지당 최대 200행 표시1~3543 레이어, 총 3543행
전체 범위 CSV 저장계산한 범위 전체를 UTF-8 BOM CSV로 저장현재 페이지와 관계없이 시작~끝 전체
복사조회 결과 또는 선택행을 머리글 포함 탭 구분으로 복사클립보드에 복사 후 표 프로그램에 붙여넣기
참고

이 기능은 위치 숫자를 계산합니다. 장비의 Z축을 움직이거나 G-code·슬라이스 이미지·원본 통합 문서를 수정하지 않습니다. 실제 장비에 적용할 값과 좌표 기준은 사용하는 공정 조건으로 확인하세요.

2. 빠른 시작 — 기본 설정으로 조회하고 전체표 저장

  1. 통합 프로그램의 ‘시퀀스별 Z값’ 탭을 엽니다. ‘사용설명서 F1’ 또는 메인 창 F1로 이 설명서를 다시 열 수 있습니다.
  2. ‘1. Z 설정’에서 초기 Z 364, 이동/피딩 하강값 0.6, 리코팅 상승값 0.5를 확인합니다. 고정 레이어 두께 0.1 안내는 읽기 전용입니다.
  3. 단일 레이어에 1을 넣고 ‘조회’를 누릅니다. 프린팅 364, Trinity 363.5, 리코팅 364가 표시됩니다.
  4. ‘3. 전체표’의 시작 1, 끝 3543을 확인한 뒤 ‘표 계산’을 누릅니다. 처음에는 1~200행이 표시됩니다.
  5. ‘다음 200행’으로 다음 페이지를 확인하거나 필요한 행을 선택해 ‘선택행 복사’를 누릅니다.
  6. ‘전체 범위 CSV 저장’을 누르고 저장 위치를 정합니다. 완료 상태와 3543행 저장 안내를 확인합니다.
  7. CSV를 표 프로그램에서 열어 머리글과 첫·끝 레이어를 확인합니다. 입력값을 수정했다면 조회 또는 표 계산을 다시 실행한 결과를 사용합니다.
참고

처음 열 때 상태는 ‘미계산’입니다. 입력란에 기본값이 보이는 것과 계산 완료 상태를 구별하세요. CSV 저장 버튼은 표 계산을 마친 유효한 범위가 있을 때 사용할 수 있습니다.

목차와 처음으로 ↑

3. 세 입력값과 고정 레이어 두께

입력기본값수식에서의 역할
초기 Z3641번 레이어 프린팅 Z의 기준
이동/피딩(Trinity) 하강값0.6프린팅 Z에서 빼는 값. 그 다음 고정 보정 +0.1 적용
리코팅 상승값0.5계산된 Trinity Z에 더하는 값
레이어 두께0.1 고정원본 두 수식에 사용된 상수이며 화면에서 변경하지 않음

세 입력에는 유한한 숫자를 사용합니다. 소수점은 마침표로 입력하고 단위 문자나 천 단위 쉼표를 붙이지 않습니다. 빈 값, 숫자가 아닌 문자열, NaN, Infinity와 같은 무한대는 사용할 수 없습니다. 표시된 값은 원본 시트와 같은 숫자·좌표 기준으로 해석하세요.

확인 사항

하강값·상승값에 음수를 넣는 것도 원본처럼 허용합니다. 하강값은 수식에서 빼므로 −0.6을 넣으면 +0.6 효과가 나고, 상승값 −0.5는 0.5를 내리는 효과가 납니다. ‘하강’·‘상승’이라는 이름만으로 부호가 자동 보정되지 않습니다.

4. 계산식과 기본값 검산

프린팅 Z = 초기 Z − (레이어 − 1) × 0.1
이동/피딩(Trinity) Z = 프린팅 Z − 하강값 + 0.1
리코팅 Z = Trinity Z + 상승값

Trinity 식의 +0.1은 원본에 포함된 보정입니다. 레이어 두께가 0.1이라는 이유로 생략하거나 하강값을 별도로 줄여 입력하지 마세요. 세 결과는 각각의 수식으로 계산하며, 리코팅 값을 프린팅 값에 단순 복사하지 않습니다.

레이어프린팅 ZTrinity Z리코팅 Z
1364363.5364
2363.9363.4363.9
35439.89.39.8
참고

기본 설정에서 프린팅 Z와 리코팅 Z가 같은 것은 −0.6 + 0.1 + 0.5 = 0이기 때문입니다. 세 입력값을 바꾸면 두 결과가 달라질 수 있습니다. 이 관계를 모든 조건에 적용하지 마세요.

5. 단일 레이어 조회와 결과 복사

  1. 조회 레이어에 1~1,000,000,000 사이의 정수를 입력합니다. 0·음수·소수 레이어는 사용할 수 없습니다.
  2. ‘조회’를 누르거나 해당 레이어 입력란에서 Enter를 누릅니다.
  3. 조회 완료 레이어와 세 Z값을 함께 확인합니다. 오류가 나타나면 입력을 고친 뒤 다시 조회합니다.
  4. ‘조회 결과 복사’를 눌러 머리글과 한 행을 클립보드에 복사합니다. Excel 등에서는 열별로 붙여넣을 수 있습니다.

조회 레이어만 바꾸면 단일 결과가 ‘미계산’으로 돌아갑니다. 기존 전체표의 범위·설정은 유지됩니다. 조회 결과가 새로 계산되기 전에는 이전 레이어의 숫자를 다시 복사할 수 없습니다.

참고

음수 Z 결과는 허용됩니다. 예를 들어 기본값으로 3642번 레이어의 프린팅 Z는 −0.1입니다. 범위를 넘어섰다는 이유로 0으로 자르거나 오류로 바꾸지 않습니다.

목차와 처음으로 ↑

6. 전체표 범위와 200행 페이지

항목규칙예시
시작 / 끝각각 1~1,000,000,000의 정수이며 시작≤끝1~3543은 3543행. 10~20은 11행
표 계산현재 설정과 시작·끝을 고정한 계산 조건을 만듦처음 200행을 즉시 표시
이전 / 다음 200행표시 페이지만 이동. 범위나 수식은 바뀌지 않음1~200 → 201~400
마지막 페이지남은 레이어만 표시1~3543의 마지막 페이지는 3401~3543, 143행

전체표는 한 번에 모든 행을 메모리에 생성하지 않습니다. 현재 페이지의 최대 200행만 계산해 표시하므로 큰 범위도 페이지를 열 수 있습니다. 다만 CSV는 범위 전체를 실제로 쓰므로 범위를 크게 잡을수록 저장 시간과 파일 크기가 늘어납니다.

참고

원본 M1 시트의 기본 표는 1~3543 레이어입니다. 기본값을 넘어서는 범위를 입력할 수 있지만 장비의 유효 작업 범위를 자동 판단하지는 않습니다.

7. 선택행 복사와 숫자 표시

  1. 표에서 필요한 행을 선택합니다. Ctrl 또는 Shift를 사용하면 여러 행을 선택할 수 있습니다.
  2. ‘선택행 복사’를 누르거나 표에 초점이 있을 때 Ctrl+C를 누릅니다.
  3. 붙여넣을 문서에서 레이어·프린팅·Trinity·리코팅 열과 선택한 행이 맞는지 확인합니다.

클립보드에는 머리글과 선택행을 탭으로 구분해 복사합니다. 다른 페이지에 있는 행은 현재 선택에 포함되지 않습니다. 범위 전체가 필요하면 CSV 저장을 사용하세요.

계산에는 Decimal 소수 연산을 사용합니다. 363.9가 363.899999처럼 보이는 이진 부동소수점 잡음을 피하고, 별도의 소수 자리 반올림을 적용하지 않습니다. 표시할 때 불필요한 끝자리 0은 줄입니다. 예를 들어 364.0은 364로 표시하며 숫자의 의미는 같습니다.

8. 입력 변경과 오래된 결과 방지

수정한 항목화면의 처리다음 작업
초기 Z / 하강값 / 상승값단일 조회와 전체표를 모두 지우고 미계산으로 표시조회·표 계산을 다시 실행
전체표 시작 / 끝전체표와 CSV 저장 조건 무효화표 계산을 다시 실행. 단일 조회는 유지
단일 조회 레이어조회 결과만 지우고 미계산으로 표시조회 다시 실행. 전체표 조건은 유지
CSV 저장 중 조건 변경 요청저장 중지 요청 후 임시 파일 정리 대기종료 상태를 확인하고 새 조건으로 재계산

일반 조작에서는 CSV 저장 동안 입력과 계산·복사 버튼이 잠깁니다. ‘표 계산 완료’ 상태의 값과 현재 입력값이 일치해야 CSV를 시작할 수 있습니다. 수정 이전 값이 화면이나 저장 조건에 남아 새 조건의 결과처럼 사용되지 않게 처리합니다.

참고

이미 완료해 저장한 CSV는 입력을 수정해도 자동 갱신되거나 삭제되지 않습니다. 새로운 조건으로 표를 다시 계산하고 새 CSV를 저장한 뒤 파일명과 저장 시점을 구분하세요.

9. 전체 범위 CSV 저장과 파일 구성

  1. 설정과 시작·끝 범위를 확인한 뒤 ‘표 계산’을 누릅니다.
  2. ‘전체 범위 CSV 저장’을 누르고 .csv 파일의 저장 위치를 정합니다.
  3. 기존 파일을 선택했다면 덮어쓰기 여부를 확인합니다. 저장이 성공적으로 끝나면 그 경로의 내용이 새 결과로 교체됩니다.
  4. 상태의 완료·저장 행 수·경로를 확인합니다. 일부 페이지를 보던 중에 저장해도 시작~끝 전체가 포함됩니다.
  5. CSV를 열어 첫·마지막 레이어와 총 행 수를 확인합니다. 데이터 행 수는 끝−시작+1이며 머리글이 한 줄 추가됩니다.
항목저장 규칙
문자 인코딩UTF-8 BOM. 한국어 머리글 포함
열 순서레이어, 프린팅 Z, 이동/피딩(Trinity) Z, 리코팅 Z
데이터 범위양 끝을 포함한 전체표 계산 범위. 페이지 선택과 무관
숫자화면과 같은 소수 문자열. 임의 반올림 없음
저장 처리같은 폴더의 임시 파일에 차례로 작성한 뒤 완료본으로 교체
참고

CSV는 워크시트나 Excel 수식 파일이 아니라 계산된 숫자의 목록입니다. 매우 큰 범위는 사용하는 표 프로그램의 행 수 제한을 넘을 수 있습니다. 필요한 범위를 나누어 저장하세요.

10. 진행 상태·중지·프로그램 종료

  • CSV 저장은 백그라운드에서 수행하며 진행률과 작성 행 수를 표시합니다. 다른 탭으로 이동해도 이미 시작한 작업은 계속됩니다.
  • 이 탭의 ‘CSV 저장 중지’ 또는 해당 탭을 선택한 상태에서 상단 ‘현재 작업 중단’을 누르면 중지를 요청합니다.
  • 중지는 임시 파일을 정리한 뒤 완료됩니다. ‘CSV 저장 중지’ 상태를 확인할 때까지 저장 위치를 다른 작업으로 변경하지 마세요.
  • 중지되거나 저장 오류가 발생하면 미완성 임시 파일을 제거하고 기존 저장 파일을 유지합니다. 임시 파일에 작성했던 행 수는 완성된 CSV의 부분 결과를 뜻하지 않습니다.
  • 저장 중 프로그램을 닫으면 중지와 정리가 끝나기를 기다린 뒤 종료합니다. 작업 관리자로 강제 종료하는 동작은 이 종료 처리에 포함되지 않습니다.
참고

완성된 CSV를 저장한 뒤에는 자동으로 이전 파일을 복원하지 않습니다. 필요한 이전 버전은 다른 이름으로 보관하세요.

12. 문제 해결과 대량 작업의 한계

증상확인할 내용해결 방법
CSV 저장 버튼이 비활성표 미계산 또는 입력 변경으로 계산 조건 무효화현재 조건으로 표 계산을 다시 실행
숫자 입력 오류빈 값, 쉼표·단위 문자, NaN·무한대마침표 소수로 된 유한한 숫자 입력
레이어 입력 오류0·음수·소수·시작>끝·10억 초과1~1,000,000,000 정수 범위와 순서 확인
리코팅이 프린팅과 다름하강·상승 설정이 기본값과 다른지세 식을 독립적으로 검산. +0.1 보정 유지
음수 결과가 나옴입력 기준 Z와 레이어 범위원본 수식의 정상 결과일 수 있음. 임의 보정하지 않기
CSV 저장 실패폴더 권한, 여유 공간, 다른 프로그램의 파일 잠금쓰기 가능한 위치나 다른 파일명으로 다시 저장
CSV가 너무 크거나 표 프로그램에서 일부만 열림전체 범위와 외부 프로그램 행 제한필요한 레이어 범위로 나누어 저장

페이지 계산은 작게 유지하지만 전체 CSV의 작성량은 실제 레이어 수에 비례합니다. 10억 레이어까지 지정할 수 있다는 것은 그 범위의 CSV가 즉시 완성된다는 뜻이 아닙니다. 작업 목적에 필요한 범위를 정하고 완료 상태를 확인하세요.

원본 M1 시트의 기본 3543개 레이어와 맞춤 소수·음수 조건을 기준으로 수식을 검증했습니다. 별도의 장비 보정, 이동 경로 안전성 판단, 엑셀 내 다른 시트의 기능은 이 탭의 계산 범위에 포함되지 않습니다.
