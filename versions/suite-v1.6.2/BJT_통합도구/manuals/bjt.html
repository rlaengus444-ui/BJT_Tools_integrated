1. 제품 개요와 작업 범위

모델·격자·STL 도구는 3D 메시를 슬라이스 이미지로 만들고, 외곽 쉘과 내부 격자를 생성한 다음 STL로 재구성합니다. 이미 보유한 슬라이스 폴더에서 시작하거나, 격자화가 끝난 이미지로 재구성 단계만 실행할 수도 있습니다. 이 설명서는 통합 프로그램에 포함된 실제 화면과 처리 경로를 기준으로 작성되었습니다.

작업 목적선택할 처리 모드실행 단계
3D 메시에서 쉘·격자 STL 만들기3D 모델 → 전체 처리모델 슬라이싱 → 쉘·격자화 → STL 재구성
기존 원본 이미지에 쉘·격자 적용기존 슬라이스 → 격자화+재구성이미지 준비 → 쉘·격자화 → STL 재구성
완성된 재료 마스크를 STL로 변환격자 슬라이스 → 재구성이미지 준비 → STL 재구성
참고

‘원본 충실형’은 지정한 DPI와 레이어 두께로 정의된 이진 복셀 표면을 보존한다는 의미입니다. 최초 CAD 곡면을 연속적으로 복원하거나 이미지보다 세밀한 정보를 생성한다는 뜻은 아닙니다. STEP 파일은 이 화면의 직접 입력 형식에 포함되지 않습니다.

본문의 기본값은 설정 파일이 없는 최초 실행 기준입니다. 이전에 저장한 설정이 있으면 해당 값이 복원될 수 있으므로, 시작 전에 화면에 표시된 수치를 확인하십시오. 예시의 수치는 조작 설명용이며 특정 모델이나 장비의 제작 조건을 보증하지 않습니다.

2. 빠른 시작

  1. 통합 프로그램에서 모델·격자·STL 탭을 열고 ‘처리 모드’를 선택합니다.
  2. ‘찾기’로 모델 파일 또는 이미지 폴더를 지정합니다. 입력 칸이 드래그앤드롭을 지원하는 환경에서는 파일이나 폴더를 끌어 넣을 수도 있습니다. 여러 항목을 놓으면 첫 항목을 사용합니다.
  3. ‘최종 STL’ 경로를 확인하고 필요하면 ‘저장 위치’에서 새 이름을 지정합니다. 입력을 바꾸면 기본 출력 경로도 다시 설정되므로 입력 선택 후 출력 경로를 확인합니다.
  4. ‘1. 슬라이싱’에서 단위·X/Y DPI·레이어 두께를 확인합니다. 이미지 입력에서는 원본 이미지 생성 시 사용한 실제 DPI와 층 두께를 직접 입력합니다.
  5. ‘2. 쉘·격자’와 ‘3. 재구성’에서 원하는 형상과 여백 설정을 확인합니다. 재구성만 하는 모드에서는 이미지의 재료 형상을 그대로 사용합니다.
  6. ‘출력·성능’에서 중간 이미지 보존 여부와 Workers를 확인한 다음 모드에 맞는 시작 버튼을 누릅니다.
  7. ‘진행 로그’와 레이어 비교 화면을 확인합니다. 완료 알림 후 최종 STL과 실행 기록 파일을 확인합니다.
확인 사항

입력 모델과 출력 STL은 서로 다른 경로여야 합니다. 같은 출력 이름으로 성공적으로 다시 실행하면 이전 STL이 교체됩니다. 작업별 결과를 보관하려면 모델명·조건·회차를 포함한 별도 파일명을 사용하십시오.

3. 입력 파일과 폴더 준비

입력 종류지원 형식 또는 규칙확인할 사항
3D 메시STL, OBJ, PLY, OFF, 3MF, GLB, GLTF빈 메시가 아니어야 하며 입력 단위를 지정합니다.
슬라이스 폴더PNG, BMP, TIF, TIFF, JPG, JPEG, WEBP선택한 폴더 바로 아래의 이미지 파일을 읽습니다. 하위 폴더는 재귀 검색하지 않습니다.
재료 판정회색조 변환 후 128 이상은 재료, 미만은 빈 공간이 화면에서는 임계값 128과 흰색 재료 판정이 고정입니다.
층 순서파일명 숫자를 인식하는 자연 정렬layer_2 다음 layer_10 순입니다. 이름의 번호 누락을 빈 층으로 자동 보충하지 않습니다.

이미지 폴더에는 검사 대상 레이어만 넣습니다. 표지·미리보기·다른 모델 이미지도 지원 확장자이면 입력에 포함됩니다. 순서가 모호한 혼합 파일명보다는 자릿수가 통일된 연속 번호를 사용하면 입력을 쉽게 점검할 수 있습니다. 빈 층이 실제로 필요하면 그 위치에 동일 크기의 검은 이미지를 명시적으로 포함합니다.

확인 사항

이미지에 기록된 DPI 메타데이터를 자동으로 가져오는 방식이 아닙니다. 화면의 X/Y DPI와 레이어 두께가 물리 크기를 결정합니다. 회색 경계가 있는 이미지도 고정 임계값으로 이진화되므로 화면상 밝기와 처리될 경계를 먼저 확인하십시오. 모든 이미지가 빈 공간이면 STL을 만들 수 없습니다.

4. 화면 구성과 모드별 조작

영역주요 조작사용 목적
상단 입력 영역처리 모드 / 입력 / 최종 STL실행할 단계와 입출력 경로 선택
1. 슬라이싱단위, DPI, 층 두께, 여백, batch3D 모델 샘플링 또는 이미지의 물리 해상도 지정
2. 쉘·격자쉘, 살 두께, 간격, 형식, 패턴, 축외곽과 내부 구조 정의
3. 재구성원본 충실형, Crop, XY 중심 정렬STL 영역과 좌표 배치 지정
출력·성능Workers, 최대 Triangle, 중간 이미지 저장자원 사용과 보존 파일 선택
레이어 비교 미리보기Layer 슬라이더 / 이미지 위 마우스 휠원본과 격자 슬라이스를 같은 순번으로 비교
진행 로그와 하단단계별 기록 / 진행률 / 시작 / 중단실행 상태와 완료·오류 확인

시작 버튼은 모드에 따라 ‘전체 처리 시작’, ‘격자화 + 재구성 시작’, ‘STL 재구성 시작’으로 바뀝니다. 실행 중에는 같은 도구의 시작 버튼이 비활성화됩니다. 진행률은 단계별 작업 진척을 표시하며 파일 크기와 형상에 따라 각 구간의 실제 소요 시간이 다를 수 있습니다.

미리보기는 각 단계가 생성한 폴더를 연결한 뒤 사용할 수 있습니다. Layer는 정렬된 파일 목록의 1부터 시작하는 순번이며 이미지의 파일명도 함께 표시합니다. 재구성 전용 모드에는 원본 슬라이스가 없을 수 있습니다. 화면은 축소 표시이므로 최종 해상도와 수치 확인은 로그·보존 이미지·STL 결과를 기준으로 합니다.

5. 슬라이싱 설정

화면 항목최초 기본값단위·범위의미와 적용
모델 입력 단위mmmm / cm / m / inch3D 입력 좌표를 mm로 환산합니다. 이미지 모드의 크기는 DPI로 정합니다.
X DPI / Y DPI400 / 400유한한 양수각 축의 픽셀 간격은 25.4 ÷ DPI mm입니다.
X/Y DPI 동일선택선택 / 해제선택하면 X DPI가 변경될 때 Y DPI를 맞춥니다. 서로 다른 해상도는 해제 후 입력합니다.
레이어 두께 (mm)0.1유한한 양수 mmZ축 한 층의 두께입니다. 이미지 모드에서도 실제 층 두께와 맞아야 합니다.
슬라이스 여백 (px)20 이상의 정수 px모델을 이미지로 만들 때 주변에 확보하는 픽셀 여백입니다.
멀티섹션 batch81 이상의 정수모델 단면을 묶어서 계산하는 요청 크기입니다. 실제 크기는 내부 자원 판단으로 제한될 수 있습니다.

3D 모델은 각 레이어 중심에서 단면을 계산하고 각 픽셀 중심의 포함 여부로 흑백화합니다. 업샘플링이나 스무딩을 추가하지 않습니다. DPI가 높거나 층 두께가 작으면 처리할 픽셀·층 수가 늘어날 수 있습니다. 기존 이미지에 더 높은 DPI를 입력해도 픽셀 정보가 추가되는 것이 아니라 해석하는 물리 크기가 달라집니다.

조작 설명용 계산 예
X/Y DPI = 400 → 픽셀 피치 = 25.4 / 400 = 0.0635 mm
이미지 폭 1,000 px → 전체 캔버스 폭 63.5 mm
100개 층 × 0.1 mm → 전체 스택 두께 10 mm
※ Crop 및 앞뒤 빈 층 제거를 적용한 결과 영역은 달라질 수 있습니다.

6. 쉘·격자 설정과 표현 한계

화면 항목최초 기본값허용값·단위동작
쉘 두께 (mm)2.00 이상의 유한한 mmXY 외곽과 Z 상·하부 cap의 보존 영역을 계산합니다. 0은 쉘 보존 두께를 두지 않는 설정입니다.
격자 살 두께 (mm)0.40보다 크고 간격보다 작은 유한한 mm격자에 사용하는 선폭 또는 벽 두께입니다.
격자 간격 (mm)2.00보다 큰 유한한 mm패턴 주기를 정합니다.
격자 형식선격자선격자 / 면격자 / 없음(쉘만)없음은 내부 격자를 만들지 않고 계산된 쉘·cap만 남깁니다.
패턴헥사고날헥사고날 / 사각육각형 또는 사각형 기반 패턴을 선택합니다.
축xyzxy / xyzxy는 2D 패턴을 층 방향으로 반복합니다. xyz는 Z 기둥과 주기적인 XY edge를 조합합니다.
쉘 계산고속 정밀 EDT (정밀도 고정)해당 항목으로 고정정밀 거리 변환 경로를 사용합니다.
참고

현재 포함된 처리 코어에서는 ‘선격자’와 ‘면격자’ 선택이 같은 래스터 패턴 경로를 사용합니다. 두 이름만으로 서로 다른 3D 형상이 생성된다고 해석하지 마십시오. 실제 구조 차이는 패턴·축·치수와 출력 미리보기로 확인합니다. ‘없음(쉘만)’은 별도로 동작합니다.

xyz의 헥사고날·사각 패턴은 모든 층에 꼭짓점 또는 교차점 위치의 Z 기둥 단면을 두고, 주기적인 층에 XY edge를 추가합니다. 내부 전체를 채운 판을 주기적으로 넣는 방식으로 설명하지 않습니다. 쉘과 cap에 해당하는 재료는 내부 격자 영역과 구분하여 보존됩니다.

코어는 쉘 또는 살 두께의 픽셀 환산값이 작거나, 간격이 너무 좁거나, Z 방향 살 두께가 한 층보다 얇으면 WARNING을 기록할 수 있습니다. 경고는 자동 치수 보정을 뜻하지 않습니다. 얇은 구조의 층별 연결 상태와 빈 공간을 보존 이미지로 확인하고 필요하면 입력 조건을 수정해 새 결과로 비교하십시오.

확인 사항

격자 생성이 생략되는 ‘격자 슬라이스 → 재구성’ 모드에서도 시작 단계는 공통 입력값을 검사합니다. 쉘은 0 이상, 격자 살 두께와 간격은 양수이며 살 두께 < 간격 조건을 유지해야 합니다. 화면에 남아 있는 잘못된 값 때문에 시작이 차단될 수 있습니다.

7. STL 재구성과 좌표 설정

화면 항목최초 기본값효과
3D 재구성원본 충실형지정된 복셀 표면을 좌표 이동·스무딩·근사 단순화 없이 병합합니다. 선택 가능한 재구성 모드는 이것 하나입니다.
XY 빈 여백 제거선택재료가 있는 XY 영역을 기준으로 빈 주변 영역을 줄입니다.
앞뒤 빈 레이어 제거선택처음과 끝의 빈 레이어를 제외합니다. 중간에 명시된 빈 레이어는 유지됩니다.
Crop 여백 (px)2XY Crop 경계에 남길 0 이상의 정수 픽셀 여백입니다.
최종 STL XY 중심 정렬선택재구성 결과의 XY 배치를 중심 기준으로 설정합니다. 원래 모델의 절대 좌표 보존과 구분해 사용합니다.

Crop은 빈 영역을 제거하는 기능이며 재료 외형을 깎는 설정이 아닙니다. 다만 원점·캔버스·빈 층이 기준인 다른 작업과 결과를 결합할 때는 좌표와 Z 범위가 달라질 수 있으므로 동일한 Crop·중심 정렬 정책을 사용했는지 확인합니다. 결과 크기는 진행 로그의 Bounds와 Extents mm에서 확인할 수 있습니다.

확인 사항

원본 복셀끼리 선이나 점으로만 닿는 형상은 엄격한 2-manifold 메시가 아닐 수 있습니다. 프로그램은 허용되는 복셀 선 접촉을 별도로 검사·보고하면서 원본 표면을 유지합니다. 자동으로 틈을 만들거나 스무딩하여 연결을 바꾸지 않습니다.

진행 로그에는 가용 RAM, 단계별 작업과 실행 시간이 기록됩니다. 실행 기록의 30분 목표 충족 여부는 해당 파이프라인의 측정값이며 프로그램 시작 준비, 외부 슬라이서 처리, 실제 장비 출력을 포함하지 않습니다. 슬라이서 RAM 계획용 수치도 추정 범위이며 특정 슬라이서에서 측정한 사용량이 아닙니다.

예시 A — 3D 모델에서 쉘·격자 STL 생성

  1. 모드를 ‘3D 모델 → 전체 처리’로 정하고 D:\BJT작업\bracket.stl을 선택합니다. 출력은 D:\BJT작업\bracket_test01_shell.stl로 지정합니다.
  2. 모델 입력 단위 mm, X/Y DPI 400, 레이어 두께 0.1 mm, 슬라이스 여백 2 px, 멀티섹션 batch 8을 입력합니다.
  3. 쉘 2.0 mm, 살 두께 0.4 mm, 간격 2.0 mm, 선격자, 헥사고날, xyz를 선택합니다. 재구성은 원본 충실형을 사용합니다.
  4. 확인용으로 원본 슬라이스 저장과 격자 슬라이스 저장을 선택하고 ‘전체 처리 시작’을 누릅니다.
  5. 진행 로그의 캔버스·층 수를 확인하고, 여러 Layer에서 외곽 보존과 내부 패턴을 비교합니다. 완료 후 STL·.run.json·보존 이미지 폴더를 함께 확인합니다.

예시 B — 기존 이미지로 쉘만 생성

  1. ‘기존 슬라이스 → 격자화+재구성’을 선택하고 D:\BJT작업\원본슬라이스 폴더를 지정합니다. 실제 이미지 조건이 400 DPI와 0.1 mm라고 가정하고 해당 값을 입력합니다.
  2. 쉘 두께를 설명용 값 1.5 mm, 격자 형식을 ‘없음(쉘만)’으로 설정합니다. 공통 검사를 통과하도록 살 두께 0.4 mm, 간격 2.0 mm는 유효한 값으로 유지합니다.
  3. 출력을 원본슬라이스_shell_only.stl로 정하고 격자 슬라이스 저장을 선택합니다. ‘격자화 + 재구성 시작’을 누릅니다.
  4. 보존된 이미지에서 XY 외곽과 위·아래 cap이 남는지 확인합니다. 얇은 부위는 쉘 영역이 겹쳐 내부가 채워질 수 있으므로 실제 결과를 확인합니다.

예시 C — 완성된 격자 이미지를 STL로 재구성

  1. ‘격자 슬라이스 → 재구성’을 선택하고 예시 A의 02_lattice_slices 폴더를 입력합니다.
  2. 이미지를 만들 때의 X/Y DPI 400과 레이어 두께 0.1 mm를 그대로 입력합니다. 이 모드에서는 새 쉘·격자를 덧붙이지 않습니다.
  3. 예시 A와 같은 Crop·XY 중심 정렬 조건을 선택합니다. 결과를 bracket_rebuild01.stl로 지정합니다.
  4. ‘STL 재구성 시작’을 누릅니다. 완료 후 Extents mm와 레이어 수, 검증 결과를 확인합니다. 서로 다른 DPI로 실험하려면 별도 이름으로 저장하여 크기 차이를 비교합니다.

11. 중단·설정 보존·문제 해결

‘중단’을 누르면 중단 요청이 전달되고 ‘현재 단계 정리 중’ 상태로 바뀝니다. 현재 수행 중인 연산이 중단 확인 지점에 도달할 때까지 기다리십시오. 중단 알림이나 오류 뒤에는 시작 버튼이 다시 활성화됩니다. 중간 이미지 저장을 선택한 작업은 중단 시 일부 이미지가 남을 수 있으며 완료 결과와 구분하여 취급합니다.

실행 시작과 종료 시 설정 저장을 시도하고 다음 실행에서 복원합니다. 재구성 모드는 원본 충실형으로 유지되며 최종 출력 경로는 입력에 따라 다시 정해집니다. 설정 저장에 실패해도 별도 오류 없이 진행될 수 있으므로 반복 작업 전 화면을 확인합니다. 통합 프로그램 전체 종료 동작은 통합 창의 작업 종료 안내를 따릅니다.

증상 또는 메시지확인과 조치
입력 경로가 없음 / 이미지가 없음실제 경로와 선택 모드를 확인합니다. 이미지가 폴더 바로 아래에 있고 지원 확장자인지 확인합니다.
슬라이스 크기가 서로 다름다른 해상도의 파일이나 미리보기가 섞였는지 확인합니다. 동일 크기의 원본 세트로 다시 준비합니다.
입력 오류: 숫자·범위소수 항목과 정수 항목을 구분합니다. DPI·층 두께·살 두께·간격은 유한한 양수, 여백은 0 이상의 정수, Workers와 batch는 1 이상의 정수입니다.
격자 살 두께는 간격보다 작아야 함살 두께 < 간격 조건을 맞춥니다. 쉘만 또는 재구성 전용 모드에서도 공통 검사값을 확인합니다.
재료 픽셀이 없음 / 표면이 없음흰색 재료·임계값 128 조건과 입력의 밝기를 확인합니다. 쉘 0과 격자 없음 조합 등 재료를 없애는 설정도 확인합니다.
Triangle 제한 초과정밀 표면을 유지하기 위한 면 수가 상한을 넘었습니다. 제한값을 검토하거나 0으로 해제합니다. 프로그램이 자동으로 단순화하지 않습니다.
RAM 또는 디스크 공간 부족가용 RAM과 임시 폴더·출력 드라이브 공간을 확보합니다. Workers를 줄여 다시 시도하고 상세 오류를 확인합니다.
STL 경계 검사 실패열린 경계·잘못된 접합·방향 오류 수를 로그에서 확인합니다. 입력 마스크 또는 원본 메시의 접촉 구조를 확인한 뒤 새 이름으로 재실행합니다.
예상과 다른 물리 크기모델 입력 단위, X/Y DPI, 레이어 두께, Crop·중심 정렬 설정을 확인합니다.
미리보기가 비어 있음해당 단계가 끝났는지, 선택 모드에 원본/격자 이미지가 존재하는지 확인합니다. 종료·다음 실행 뒤에는 임시 미리보기 자료가 정리될 수 있습니다.

문제를 재현할 때는 처리 모드, 입력 파일명·층 수·이미지 크기, 화면 수치, 최종 로그의 오류, 해당 출력 이름의 .run.json을 함께 기록합니다. 같은 이름으로 재실행하기 전에 필요한 실패 기록과 이전 정상 결과를 별도 보관하면 비교가 쉽습니다.
