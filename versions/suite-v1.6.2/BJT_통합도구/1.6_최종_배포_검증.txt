BJT 통합프로그램 1.6.0 최종 배포 검증 — 2026-10-24 UTC

결과
- 전체 통합 시험 200개 중 199개 통과, 외부 원본 참조 파일이 없는 기존 시험 1개 건너뜀.
- 하위 시험 97개 통과. 실패/오류 0. 신규 치투 엔진 64개 및 GUI 연동 14개 모두 통과.
- 기존 10개 도구와 5개 지원 코드가 1.5판과 바이트 일치.
- 배포 EXE의 내장 라이브러리/23개 소스 해시/Manifold/FCL/오프라인 Plotly 진단 통과.
- GUI EXE에서 11개 탭 열기/초기화/종료 통과.
- 실제 공정파일 GUI 검사 17항목 통과: 63개 오브젝트/1,953쌍,
  간격 3 mm에서 쌍 15/31 FAIL, 1 mm에서 PASS, JSON/선택 쌍 3D HTML,
  입력 변경 결과 무효화, 중단 및 작업 정리 후 종료, 원본 보존.
- 명령줄 EXE: 실제 파일 기준 1 mm→종료 0, 3 mm→종료 1, 형식 미지원→종료 2.
  영문 코드페이지에서 한글 UTF-8 출력과 JSON/HTML 저장 확인. Python은 PATH에서 제외.
- 기존 모델/슬라이싱/번호/CSV/ZIP 등 동결 EXE의 전체 출력 회귀 시험 통과.
- VC++ 런타임 참조 1,083건의 DLL/함수 누락 0. 필요한 재배포 DLL/라이선스 동봉.
- Windows OS의 UCRT/GDI+/WindowsCodecs DLL은 배포하지 않음.
- 소스와 동결 앱의 실행 코드/설명서 57개 자산 바이트 일치.

실제 입력
- 공정기록의 .chitubox 3개를 검증. 원본은 수정하지 않음.
- 20261012-M1-1: 최소 간격 2.924621820449829 mm.
- 261014-M1-1 살추가 O/X: 각각 열린 메쉬 2개. 55쌍 통과/23쌍 미판정으로 전체 판정 불가.
- 실제 메쉬 복사본의 접촉/침투/0.5 mm 간격 미달/정확히 1 mm 경계 시험 통과.

검증 환경과 범위
Windows x64 바이너리를 Linux Docker의 Wine 10 호환 환경에서 실행했다.
Python 3.12.10, NumPy 2.3.5, trimesh 5.1.0, Manifold 3.5.4, python-fcl 0.7.0.11.
별도의 깨끗한 Windows 10/11 VM 시험은 수행하지 않았다.
M2의 사전 Wine 코덱 차이는 테스트 환경에 Microsoft 라이브러리를 적용해 해결했고,
프로그램의 기존 M2 알고리즘은 변경하지 않았다.
건너뛴 시험은 이전 원본 FileNumberDuplicatorPlus 외부 파일과의 비교 1건이다.
이전 1.5판의 검증 이력과 이번 1.6판의 새 결과를 구분해 보관한다.
상세 JSON/XML 증거는 검증_결과/1.6에 있다. 원본 치투 프로젝트는 배포하지 않는다.
