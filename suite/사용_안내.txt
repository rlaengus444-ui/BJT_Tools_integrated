BJT 통합 작업 도구 1.7.0 — 사용 안내
문서 갱신: 2026-10-26 (Asia/Seoul)

실행
- Windows 10·11 64비트용입니다. EXE판은 Python·Excel·.NET을 따로 설치하지 않습니다.
- EXE 배포본 전체를 압축 해제한 뒤 BJT_통합프로그램.exe를 실행합니다.
- 분할 배포본이면 배포 페이지의 복원 안내를 먼저 따르세요.
- EXE 옆의 _internal 폴더를 함께 유지합니다. EXE만 다른 위치로 꺼내면 실행되지 않습니다.
- BJT_명령줄.exe는 명령줄 작업용입니다. 일반 사용은 BJT_통합프로그램.exe를 엽니다.
- 첫 화면이나 상단 목록에서 사용할 기능을 선택합니다.
- 소스판은 Python이 필요합니다. 폴더 안에서 python run_suite.py를 실행하거나 .pyw 실행 파일을 엽니다.

입력값 자동 저장
- 통합 프로그램을 정상 종료하면 11개 기능의 입력값을 사용자별로 저장합니다.
- 다음 실행에서 해당 탭을 열 때 값을 복원합니다. 열지 않은 탭의 이전 설정도 유지합니다.
- 공통 설정이 없는 모델·격자·STL, 슬라이싱 배치·합성, 오븐은 1.6.2의 기존 설정을 먼저 읽습니다.
  이후에는 공통 설정을 우선하며 이전 설정 파일은 수정·삭제하지 않습니다.
- 숫자·선택·체크 상태·경로·입력 목록·배치·프로파일을 저장합니다.
- 이미지 변환의 사용자 픽셀·DPI, 오븐의 언어와 불러온 열전대 수치도 저장합니다.
- 설정 파일: %LOCALAPPDATA%\BJT_Tools\settings.json
  Linux 소스판: $XDG_CONFIG_HOME/BJT_Tools/settings.json 또는 ~/.config/BJT_Tools/settings.json
- 원본 이미지·메쉬·변환 캐시·계산 결과·로그·진행 중 작업은 설정 파일에 포함되지 않습니다.
  원본 파일을 이동했다면 복원된 경로를 확인하세요. 복원만으로 작업을 자동 실행하지 않습니다.
- 작업 중 창을 닫으면 중단·파일 정리를 기다린 뒤 저장하고 종료합니다.
- 강제 종료나 전원 차단 직전 변경은 저장되지 않을 수 있습니다.
- 저장 실패는 경고와 오류 기록을 남기며 기존 설정을 보존합니다.
  손상된 설정은 기본값으로 시작하고, 다음 저장 시 .corrupt-시각 이름으로 보관합니다.

기능
1. 모델·격자·STL: 3D 모델·슬라이싱 이미지에서 쉘·격자 STL 생성.
2. 슬라이싱 배치·합성: 이미지·STL 이동·회전·복제·레이어 합성.
3. 폴더 겹치기: 여러 슬라이싱 폴더를 레이어별로 합성.
4. 슬라이싱 교체: 번호 범위 교체·백업·교체 후 검사·실패 시 복구.
5. 슬라이싱 위치 검사: 교체 경계와 인접층의 위치 이동 확인.
6. 오븐 열확산 시뮬레이터: 분말층·빌드박스 열전달, 선택적 산소 확산, 열전대 보정.
7. 슬라이싱 일치성 검사: 폴더·ZIP의 픽셀·위치·해상도·비트 수·형식 비교.
8. 번호 복제·누락 검사: 번호 범위 복제와 누락·중복 번호 확인.
9. 시퀀스별 Z값: M1의 레이어별 프린팅·이동/피딩·리코팅 Z값 조회·CSV 저장.
10. 이미지 변환: 사용자 픽셀 크기·X/Y DPI의 4비트 반전 TIFF·LZW 변환.
11. 치투 오브젝트 검사: 겹침·표면 접촉·최소 간격(mm) 검사와 문제 쌍 3D 확인.

이미지 변환
1. 싱글·멀티 기본 규격을 고릅니다. 싱글은 8504×6614px / 400×400DPI,
   멀티는 8504×13228px / 400×800DPI입니다.
2. 필요하면 가로(px)·세로(px)·X DPI·Y DPI를 각각 수정합니다.
   픽셀 크기는 리사이즈를, DPI는 별도의 출력 해상도 정보를 정합니다.
   기본 규격을 바꾸거나 ‘기본값 적용’을 누르면 네 값이 기본값으로 바뀝니다.
3. 이미지나 폴더를 추가하고 목록 순서·출력 폴더·번호·충돌 정책을 확인합니다.
4. ‘변환 시작’을 누릅니다. 모든 새 TIFF의 실제 픽셀·DPI·4비트·LZW 형식을 확인한 뒤 저장합니다.
   기본 건너뛰기로 남긴 기존 파일은 새 규격으로 다시 변환하지 않습니다.

치투 오브젝트 검사
1. .chitubox/.chitu 한 개 또는 개별 STL 여러 개를 ‘검사 파일’ 영역에 끌어놓습니다.
   STL은 기존 STL 목록에 추가하며 같은 경로는 중복 추가하지 않습니다.
   프로젝트와 STL을 섞거나 프로젝트 여러 개를 동시에 넣을 수는 없습니다.
2. 입력을 바꾸려면 ‘파일 선택’을, STL 폴더는 ‘STL 폴더’를 이용합니다.
   끌어놓기를 지원하지 않는 환경에서도 이 버튼을 사용할 수 있습니다.
3. 최소 간격(mm)을 입력하고 ‘검사 시작’을 누릅니다. 표면 접촉은 간격 0에서도 FAIL입니다.
4. 판정 완료 여부와 문제 쌍을 확인하고 ‘3D 배치 보기’ 또는 ‘JSON 저장’으로 기록합니다.
   판정 불가나 중단은 PASS가 아닙니다. 원본 배치 좌표와 mm 단위를 유지하세요.

오븐 열확산 시뮬레이터
- 입력 영역 상단 ‘언어’에서 한국어·English를 선택합니다. 처음 실행은 한국어입니다.
- ‘입력값 설명서’는 기존의 한국어 상세 안내입니다. 영어 모드에서는 Input guide (Korean)입니다.
- 열전달·금속판 결합·대류·복사·바닥 공기층 모델은 유지했습니다.
- 농도가 변하는 산소 계산에는 공극률에 따른 저장량을 반영합니다.
  이전 버전과 산소 유입 시간·노출량이 달라질 수 있으므로 같은 조건도 다시 계산하세요.
- PSD의 D32는 개수 기준 로그정규 분포 가정입니다. 체적 기준 입도 자료와 혼동하지 마세요.
- 자세한 수식·모델 범위는 사용설명서와 1.7.0_변경_및_물리모델_검토.md를 확인합니다.

설명서와 결과 보관
- 각 탭 상단 ‘사용설명서 F1’, 첫 화면 ‘사용설명서’, 상단 ‘사용 안내’에서 설명서를 엽니다.
- manuals/index.html은 인터넷 없이 열 수 있는 전체 설명서 목록입니다.
- Ctrl+F로 검색, F3/Shift+F3로 검색 이동, A+/A−로 글자 크기를 조절합니다.
- 계산 결과는 CSV·JSON·HTML·STL 등 필요한 파일로 따로 저장합니다.
- 검증 범위와 실제 결과는 통합_검증_보고서.txt 및 검증_결과 폴더를 확인하세요.
