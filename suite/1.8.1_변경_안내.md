# BJT 통합프로그램 1.8.1 변경 안내

2026년 11월 2일

배치 분리 확인과 형상 유효성 검증을 구분합니다. 유한한 원본 삼각형의 경계 상자로 분리가 입증된 쌍은 별도 표시하며, 닫힌 입체 형상 경고와 기존 PASS 조건을 유지합니다. 전체 오류는 스크롤하여 확인할 수 있습니다.

치투 배치보기에서 표시 예산을 초과하는 형상도 원본 위치를 유지한 축소 미리보기로 볼 수 있도록 개선했습니다. 화면에는 축소 표시 여부를 알리며, 검사와 저장에는 원본 형상을 사용합니다. 형상 오류나 검사가 완료되지 않은 항목은 계속 확인이 필요합니다.

각 도구의 화면 결과·표·그래프·로그를 소수 둘째 자리까지 표시합니다. 아주 작은 0이 아닌 값은 과학적 표기법으로 표시하고, 보장된 하한값은 실제 하한을 넘지 않도록 내림 표시합니다. 계산, 입력값 및 저장·내보내기 정밀도는 유지합니다.
