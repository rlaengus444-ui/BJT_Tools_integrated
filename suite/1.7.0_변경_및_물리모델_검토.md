# BJT 통합 작업 도구 1.7.0

2026-10-26 · 팀드라이브의 통합프로그램 1.6.2 소스를 기준으로 수정했습니다.

## 화면과 입력

- 첫 화면은 프로그램 이름과 기능 선택으로 정리했습니다.
- `M2 이미지 변환`을 `이미지 변환`으로 바꾸고 가로·세로 픽셀, X/Y DPI를 각각 입력하도록 했습니다. 싱글·멀티는 기존 수치의 기본 규격이며, 기본값을 적용하면 사용자 입력값을 대체합니다.
- 픽셀 수 변경은 전체 사각형 리사이즈입니다. DPI만 바꾸면 목표 픽셀 수는 그대로이며 출력 해상도 정보를 바꿉니다. 기존 GDI+ 리사이즈·4비트 반전 팔레트·LZW TIFF 처리 순서는 유지합니다.
- 통합 프로그램 정상 종료 시 11개 기능의 입력값·입력 목록·배치·오븐 프로파일·언어·불러온 열전대 수치를 사용자별로 저장합니다. 다음 실행에서는 열어 본 탭부터 복원하며 작업은 자동 시작하지 않습니다.
- 치투 검사는 프로젝트 한 개 또는 개별 STL 여러 개를 끌어놓아 입력할 수 있습니다. STL은 목록에 추가하고 중복 경로를 제외합니다. 검사 중에는 입력을 바꾸지 않습니다. 드롭을 사용할 수 없는 환경에는 파일 선택 버튼이 남습니다.
- `열·산소 확산`을 `오븐 열확산 시뮬레이터`로 바꾸고 한국어·English 선택을 추가했습니다. 처음 실행은 한국어입니다. 상세 입력 가이드는 한국어이며 영어 화면에서 이를 표시합니다.

## 열전달 모델

분말층의 보존형 3차원 유한체적 열전도, 별도 열용량을 가진 측벽·바닥판, 대류·복사 경계와 바닥 공기층 열전달은 유지했습니다. 열전도율은 직접 입력·입도 기반 추정·실측 보정 중 선택합니다.

균질한 다공성 분말층을 가정합니다. 바인더 반응열·수분 및 용매 잠열·산소 소비·압력 구동 유동·상세 오븐 유동·개별 부품 형상은 새로 추가하지 않았습니다. 온도 이력의 적합성을 확인할 때는 실측 충전 밀도와 열전대 자료, 격자·시간 간격 민감도를 함께 검토해야 합니다.

## 산소 공극 저장량 보완

산소 상태값 `c`는 기공 가스의 실제 체적분율입니다. 벌크 체적당 저장량은 공극률 `ε`를 곱한 `εc`이므로 다음 식을 사용합니다.

```text
ε ∂c/∂t = ∇·(D_eff ∇c)
D_eff = ε D_pore / τ
```

일정 공극률에서 농도 변화 계수는 `D_eff/ε = D_pore/τ`입니다. 이전 계산에서 빠져 있던 저장량의 공극률을 반영했고, 농도가 변하는 경우의 시간 간격 안정성에도 같은 계수를 사용합니다. 화면·CSV의 `D_eff`는 기존처럼 벌크 단면적 기준 플럭스 계수이며 의미를 바꾸지 않았습니다.

초기 산소와 외부 산소가 같으면 소비·반응이 없는 모델에서는 농도가 균일하게 유지됩니다. 이 경우에는 기존 열 계산의 시간 간격과 결과를 유지하는 경로를 사용합니다. 농도가 다른 경우에는 이전 버전보다 산소 유입 시간과 노출량이 달라질 수 있으므로 기존 산소 결과를 그대로 재사용하지 마세요.

## 시간 간격과 입력 검증

계산된 안정성 시간 간격을 고정 최솟값으로 올리는 처리를 제거했습니다. 작은 형상이나 촘촘한 격자에서 필요한 작은 시간 간격을 그대로 사용하므로 계산 시간이 늘어날 수 있습니다. 계산 격자나 물리량을 자동으로 낮추지는 않습니다.

유한하지 않은 물리 입력, 절대영도 이하의 초기·오븐 온도, 정수가 아닌 격자 등은 계산 전에 거부합니다. 이 검증은 입력 형식을 확인하는 절차이며 모든 온도 범위에서 물성 근사가 실험적으로 검증됐다는 뜻은 아닙니다.

## D32와 입도 기준

기존의 다음 D32 식은 유지했습니다.

```text
σ = ln(D90/D10) / (2 × 1.2815515655446004)
D32 = D50 × exp(2.5 σ²)
```

이 식은 **개수 기준 로그정규 분포**의 모멘트 비 `M3/M2`를 추정합니다. 레이저 회절 등 체적 기준 입도 누적분포를 그대로 같은 식에 적용하면 D32와 공극 길이 추정이 달라질 수 있습니다. 측정 자료의 분포 기준이 확정되지 않았으므로 분포를 임의로 자동 변환하거나 수식을 교체하지 않았습니다.

## 저장과 검증 기록

모델·격자·STL, 슬라이싱 배치·합성, 오븐은 해당 도구의 공통 설정이 없을 때 1.6.2의 기존 설정을 먼저 읽습니다. 이후에는 공통 설정을 우선하며 이전 파일을 수정·삭제하지 않습니다.

Windows 통합 입력 저장 경로는 `%LOCALAPPDATA%\BJT_Tools\settings.json`입니다. 원본 이미지·메쉬, 계산 결과와 로그는 설정에 포함되지 않습니다. 정상 종료 때 저장에 실패하면 경고를 표시하고 기존 파일을 보존합니다. 손상 파일은 다음 저장 때 별도 이름으로 보관합니다.

각 기능의 사용법은 `manuals/index.html`에 있습니다. 최종 통합·EXE 시험의 실행 환경과 실제 통과·실패 수는 배포본의 `통합_검증_보고서.txt`와 `검증_결과`를 기준으로 확인합니다.
