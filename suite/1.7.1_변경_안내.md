# BJT 통합 작업 도구 1.7.1

2026-10-26 · 1.7.0의 오븐 3D 결과 화면에서 재생 조작이 가려지는 문제를 수정했습니다.

## 오븐 3D 재생

`3차원 온도 분포`와 `3차원 산소 농도 분포`의 조작 영역을 그래프 위쪽에 고정했습니다. 그래프는 남은 공간을 사용하고, 프레임 시간·범위는 버튼 아래 별도 줄에 표시합니다.

| 한국어 | English | 동작 |
| --- | --- | --- |
| 재생 | Play | 현재 프레임 다음부터 순서대로 반복 재생 |
| 일시정지 | Pause | 현재 프레임을 유지하고 자동 재생만 멈춤 |
| 정지 | Stop playback | 자동 재생을 멈추고 첫 프레임으로 이동 |
| ◀ / ▶ | ◀ / ▶ | 이전·다음 저장 프레임 선택 |

슬라이더로 저장 시점을 직접 선택할 수도 있습니다. 온도·산소 화면의 재생은 각각 조작합니다.

프레임이 2개 이상일 때 재생·이전/다음을 사용할 수 있고, 일시정지는 재생 중에 활성화됩니다. 프레임 한 개에서는 자동 재생·이전/다음이 비활성이고 슬라이더의 시점도 하나뿐이지만 정지로 첫 프레임을 확인할 수 있습니다. 해당 3D 결과가 없으면 재생 조작은 비활성입니다. 산소 화면은 산소 계산을 켠 실행에 저장 프레임이 있어야 사용할 수 있습니다.

이 조작은 저장된 결과의 화면 표시만 바꿉니다. 시뮬레이션 작업·계산 결과·입력값을 중단하거나 지우지 않습니다. 실행 중 계산·보정을 중단하려면 입력 영역의 `중단 / Stop`을 사용합니다.

## 기존 기능과 설정

1.7.0의 이미지 픽셀·DPI 설정, 11개 기능 입력값 저장, 치투 끌어놓기, 오븐 한국어·영어 및 물리 모델 보완은 유지합니다. 물리 모델의 자세한 변경은 `1.7.0_변경_및_물리모델_검토.md`를 확인하세요.

사용법은 `manuals/index.html`에 있습니다. 최종 통합·EXE 시험 환경과 결과는 `통합_검증_보고서.txt`와 `검증_결과`를 기준으로 확인합니다.
