1. 제품 개요와 적용 범위

오븐 열확산 시뮬레이터는 직육면체 빌드박스에 채운 SiC 분말층을 3차원 격자로 나누고, 사용자가 지정한 오븐 온도 이력에 따른 분말·금속 측벽·바닥판의 가열 및 냉각을 계산합니다. 중심 온도의 지연, 분말층 내부 온도 편차, 설정 온도 이상에서 머문 누적 시간을 확인할 때 사용합니다. 선택한 경우 같은 공간 격자와 시간 간격으로 산소의 확산도 함께 계산합니다.

  • 주요 입력: 분말 충전 영역의 치수, 빌드박스 재료와 두께, 분말 밀도·열물성·입도, 열전달 경계, 오븐 시간·온도 표, 계산 격자.
  • 주요 결과: Temperature history, 3D temperature field, O₂ history, 3D O₂ field의 네 화면과 22열 결과 CSV.
  • 선택 기능: 중심 열전대 CSV를 이용한 PSD 열전도율 배율 및 대류계수의 동시 보정.
  • 공간 좌표는 mm, 화면 온도는 °C, 프로파일 시간은 min, 이력 그래프 시간은 h를 사용합니다. 입력 칸 옆의 단위를 우선 확인하십시오.
확인 사항

이 프로그램은 균질한 다공성 분말층을 가정한 계산 도구입니다. 바인더 반응열, 용매·수분 증발 잠열, 산소 소비, PVP 반응속도, 분말층 내부의 압력 구동 유동 및 자연대류는 계산하지 않습니다. 본 설명서의 예시는 조작 연습용이며 생산 조건의 인증값이나 품질 보증 기준이 아닙니다.

분말 내부의 개별 부품 형상이나 STL은 이 탭에 입력하지 않습니다. X·Y·Z는 부품의 외형 치수가 아니라 실제 분말이 채워진 영역의 치수입니다. 세부 형상에 따른 국소 반응이나 실제 오븐 유동을 직접 재현하는 기능으로 해석하지 마십시오.

3. 빠른 시작 — 첫 해석 완료하기

  1. 저장된 조건이 자동 복원되어 있는지 확인합니다. 처음부터 시작하려면 Reset defaults를 누르고 초기화를 승인합니다. 기본 조건은 입력 시작점이며 실제 사용 조건으로 확정된 값은 아닙니다.
  2. 1) Powder-filled region에 실제 분말 충전 영역 X·Y·Z를 mm로 입력합니다. 2) Build box에서 재질, 두께, 바닥 간격 및 상부 개방 여부를 확인합니다.
  3. 3) SiC powder bed / k_eff model에서 Bed density와 True density를 g/cc로 입력합니다. 첫 비교 연습에서는 Manual 모드와 Manual k_eff를 지정하거나, 입도 자료가 있으면 PSD estimate를 선택합니다.
  4. 4) Oven heat transfer에서 Convection h, Effective emissivity, Initial bed temp를 확인합니다. 산소가 필요 없다면 Enable O₂ diffusion-only simulation을 해제합니다.
  5. 7) Numerical settings에서 각 격자를 3 이상 100 이하의 정수로 지정합니다. Max Δt는 초, Output interval은 초, 3D snapshot interval은 분입니다.
  6. 8) Oven profile 표를 작성합니다. 첫 시간이 0 min인지, 시간이 중복되지 않고 증가하는지 확인합니다. 최소 두 점이 필요하며 마지막 점의 시간이 해석 종료 시간입니다.
  7. Run simulation을 누릅니다. 오류가 나오면 해당 입력을 수정한 뒤 다시 시작합니다. 상태가 Completed가 되면 네 결과 탭과 요약을 검토합니다.
  8. Export CSV를 눌러 저장 위치와 이름을 지정합니다. 다음 작업에서도 같은 조건이 필요하면 Save inputs로 저장합니다.

기본 프로파일은 0/25, 60/80, 120/80, 180/120, 240/120, 330/200, 1050/200, 1170/80의 시간[min]/온도[°C] 조합입니다. 330→1050 min 구간은 200°C에서 720분, 즉 12시간 유지입니다. 마지막 1170 min은 시작 후 총 19.5시간을 의미합니다.

참고

시간이 오래 걸려도 계산 창의 상태와 진행률을 먼저 확인하십시오. PSD 보정은 같은 3차원 해석을 반복하므로 일반 실행보다 오래 걸릴 수 있습니다. 중단할 때는 Stop을 누른 후 Stopped / error 상태로 돌아올 때까지 기다립니다.

4. 분말 영역과 빌드박스 입력

분말 영역은 X×Y×Z의 직육면체입니다. 금속 측벽 네 장과 바닥판은 분말과 별도의 온도장·열용량을 가지며, 금속 내부의 면내 열전도와 측벽에서 바닥판으로 이어지는 열전달을 계산합니다. 닫힌 상부 덮개는 별도 열용량을 가진 금속판으로 해석하지 않고 열저항으로 처리합니다.

Material을 바꾸면 해당 재료의 Wall k, Wall density, Wall cp가 프리셋 값으로 다시 채워집니다. 사용자 측정값을 사용할 때는 먼저 재료를 선택하고 그다음 물성을 수정하십시오. Custom을 선택할 때도 시작값이 채워지므로 필요한 값을 다시 확인합니다. 단순히 표시 재료명만 바꾸는 동작은 아닙니다.

확인 사항

Under-plate gap은 산소 공급 경로나 강제 송풍 입력이 아닙니다. 이 간격의 열전달은 수평 공기층의 자연대류·전도 및 바닥 복사로 처리합니다. 오븐 바닥 온도는 입력한 오븐 프로파일과 같다고 가정합니다.

5. SiC 물성·밀도·입도 설정

분말의 충전 상태는 Bed density와 True density의 비로 반영됩니다. Solid fraction = Bed density / True density, Porosity = 1 − Solid fraction입니다. 예를 들어 1.700/3.210이면 고체 체적분율은 약 0.530, 공극률은 약 0.470입니다. GUI의 두 밀도 입력은 g/cc이며 내부 계산 때 각각 1000을 곱해 kg/m³로 변환합니다.

SiC preset을 바꾸면 True density, cp, Solid SiC k 기준값이 갱신됩니다. α-SiC 프리셋의 고체 열전도율은 100 W/mK, SiC general과 β-SiC는 80 W/mK에서 시작합니다. 프리셋은 측정값을 대신하는 확정 물성이 아니며 이후 각 칸을 수정할 수 있습니다.

D10·D50·D90은 µm 단위의 입도 누적 백분위 값입니다. 프로그램은 이 세 값으로 로그정규 분포 폭, Span 및 D32 추정치를 만들고, 공극 특성 길이와 복사·Knudsen 보정에 사용합니다. 입도 값만으로 실제 입자 접촉저항이나 공극 목 직경을 직접 측정한 것으로 보지 마십시오.

확인 사항

D32 = D50·exp(2.5σ²)는 입력 분포를 개수 기준 로그정규 분포로 가정한 추정식입니다. σ = ln(D90/D10)/(2×1.2815515655)입니다. 레이저 회절 등으로 얻은 체적 기준 누적 입도를 그대로 넣어 같은 D32가 된다고 해석하지 마세요. 측정 분포의 기준을 확인해야 하며 프로그램은 분포 기준을 자동 변환하지 않습니다.

6. k_eff 모드 선택과 미리보기

모드실제 계산관련 입력
Manual온도와 위치에 관계없이 상수 k_eff 사용Manual k_eff
PSD estimate각 셀의 국소 온도로 고체·기체 전도, 접촉 혼합, 공극 복사를 계산밀도, D10~D90, Solid/Pore-gas k, n, Contact blend, Effective emissivity
CalibratedPSD estimate의 k_eff(T)에 Calibrated k scale을 곱함PSD 입력 전체 + k scale + Calibrated h
  1. k_eff mode를 선택하고 해당 모드의 입력을 채웁니다. Manual은 유효 열전도율을 직접 지정하는 비교에 사용합니다. PSD estimate는 입도와 밀도를 사용한 온도 의존 추정을 확인할 때 사용합니다.
  2. Preview k_eff(T)를 눌러 현재 조건으로 계산된 값을 확인합니다. Porosity와 PSD 표시도 함께 확인하여 단위·입도 순서의 잘못을 찾습니다.
  3. Calibrated를 수동으로 선택했다면 Calibrated k scale과 Calibrated h를 모두 양수로 입력합니다. 열전대 보정을 수행한 경우에는 보정 완료 후 이 두 칸과 모드가 자동 갱신됩니다.
  4. 조건을 확정한 뒤 Run simulation을 실행합니다. 미리보기는 전체 공간·시간 해석을 실행하거나 기존 결과를 갱신하는 버튼이 아닙니다.

Calibrated에서는 4) Oven heat transfer의 Convection h 대신 6) Center thermocouple calibration의 Calibrated h를 사용합니다. 다른 두 모드는 Convection h를 사용합니다. 두 값이 화면에 함께 남아 있어도 실제 적용 값은 선택 모드에 따라 달라지므로 CSV의 k_eff_mode와 실행 요약을 함께 확인하십시오.

참고

Manual 열전도 모드라도 산소 해석을 켜면 D10·D50·D90 검증이 적용됩니다. 산소 확산 모델이 입도를 참조하기 때문입니다. 사용하지 않는 입력도 수집 단계에서 숫자로 읽으므로 빈칸 대신 유효한 숫자를 유지하십시오.

PSD estimate는 Maxwell 계열 및 기하평균 전도 추정값을 로그 공간에서 혼합하고, 입도 폭을 약하게 반영한 접촉 항과 온도에 따른 복사 항을 더합니다. Calibrated도 이 모델 구조 자체를 바꾸지는 않습니다. 특정 실험의 중심 곡선과 맞는 배율을 얻었다는 사실만으로 모든 형상·프로파일에서 동일 정확도가 보장되지는 않습니다.

오븐 공기 온도는 프로파일 점 사이를 직선 보간합니다. 측벽은 오븐과의 열교환, 금속 자체 열전도 및 분말과의 결합을 계산합니다. 바닥판은 측벽과 연결된 금속 전도, 오븐 바닥으로부터의 복사, 하부 공기층 자연대류·전도의 영향을 받습니다. 하부 공기층에 강제대류 항은 적용하지 않습니다.

Top is open to oven air는 상부의 열저항 처리 선택입니다. O₂ access boundaries의 Top과는 별도의 체크 항목입니다. 열적으로 덮개를 닫고 산소 상부 접근을 켜는 조합도 입력상 가능하므로, 의도한 경계 조건인지 사용자가 확인해야 합니다. 산소와 열의 경계 선택이 자동으로 서로 전환되지는 않습니다.

  1. Initial bed temp를 해석 시작 시점의 조건과 맞춥니다. 프로파일 첫 온도와 반드시 같아야 하는 것은 아니며, 차이를 주면 시작부터 온도차에 의한 열전달이 생깁니다.
  2. 개방 상부 또는 덮개 여부를 선택합니다. 덮개를 사용하는 경우 Top/lid thickness와 금속 k를 함께 확인합니다.
  3. Under-plate gap, Oven-floor emissivity, Floor view factor를 확인합니다. 이 세 항목을 바꾸면 바닥판의 열유입 경로가 바뀝니다.
  4. 결과에서 side-wall average, bottom-plate average와 분말 center를 비교합니다. 금속 온도와 분말 중심 온도를 같은 위치의 값으로 해석하지 않습니다.
확인 사항

오븐 온도 곡선은 실제 장비를 제어하지 않습니다. 이 탭은 입력 프로파일을 읽어 계산만 수행합니다. 오븐 바닥과 공기의 온도 차이, 상세 유동, 증발 및 반응열은 별도로 풀지 않으므로 결과가 나타내는 계산 범위를 유지해 해석하십시오.

8. 산소 확산 설정과 해석 범위

Enable O₂ diffusion-only simulation을 켜면 분말 공극의 산소 농도를 확산 방정식으로 계산합니다. 농도는 실제 기상 등가 vol%이며 20.95를 입력하면 내부에서는 0.2095 체적분율로 사용합니다. 초기 농도는 전 영역에 균일하게 주어지고, 접근을 허용한 면의 기하학적 경계에는 Ambient O₂가 지정됩니다.

Bruggeman 모드에서는 τ = 공극률^(−1/2), 유효 확산계수는 공극 확산계수×공극률/τ로 계산합니다. Manual에서는 사용자가 입력한 τ를 적용합니다. 자유 기체 확산계수는 절대온도 비의 지수 함수로 바뀌고, Knudsen 선택 시 분자 확산과 Knudsen 확산의 역수 합으로 공극 확산계수를 구합니다. Preview O₂ diffusivity로 현재 조건의 수치를 확인할 수 있습니다.

산소 농도 c는 공극 가스의 실제 체적분율이며 공극률 ε는 저장 가능한 가스 체적 비율입니다. 계산식은 ε·∂c/∂t = ∇·(D_eff·∇c)이고 D_eff = ε·D_pore/τ입니다. 따라서 일정 공극률에서 농도 변화에 사용하는 계수는 D_eff/ε = D_pore/τ입니다. 화면과 CSV의 D_eff는 기존과 같이 벌크 단면적 기준 확산 플럭스 계수이며, 농도 변화 계수와 구별합니다.

확인 사항

초기 O₂와 외부 O₂가 같으면 산소를 소비하는 반응이 없으므로 농도는 균일하게 유지됩니다. 이는 오류가 아닙니다. 낮은 초기 농도를 지정하는 예시는 산소가 부족한 상태에서의 순수 유입을 관찰하는 연습입니다. 바인더 산화·가교 정도나 소모량을 예측하는 기능으로 사용할 수 없습니다.

Top과 Sides를 모두 끄면 해당 면은 외부 산소를 공급하지 않습니다. Sides는 실제 금속 측벽의 개구를 자동 추정하지 않고 사용자가 부여한 확산 경계입니다. 산소 계산은 대략 대기압 조건의 기체 확산을 가정하며 압력 변화, 가스 흐름 및 열천이 유동을 포함하지 않습니다. 산소 계산을 끄면 관련 이력은 계산하지 않고 CSV의 산소 관련 항목은 NaN으로 남습니다.

참고

1.7.0은 농도가 변하는 산소 계산에 공극률에 따른 저장량을 반영합니다. 같은 입력이라도 이전 버전과 산소 유입 시간·노출량이 달라질 수 있으므로 새 버전으로 다시 계산하세요. 초기 농도와 외부 농도가 같으면 이전과 같이 균일하게 유지됩니다. 반응·산소 소비 항을 추가한 것은 아닙니다.

9. 오븐 프로파일 작성과 편집

Oven profile (absolute elapsed time)은 시작 후 절대 경과 시간과 오븐 온도를 짝으로 입력하는 표입니다. 각 행의 시간은 이전 행에서 지난 시간이 아닙니다. 프로그램은 행 사이를 직선으로 연결하므로 같은 온도의 서로 다른 시간 두 점을 만들면 유지 구간이 됩니다. 마지막 행의 시간이 전체 해석 길이를 결정합니다.

  1. 기존 표를 확인합니다. 새 표를 만들 때는 필요 없는 행을 선택하고 Delete를 눌러 제거합니다.
  2. Add point를 누르고 Elapsed time [min], Oven temperature [°C]를 입력한 뒤 OK를 누릅니다. 시간은 음수가 될 수 없습니다.
  3. 수정하려는 행을 선택하고 Edit를 누릅니다. 여러 행이 선택되었다면 편집은 첫 선택 행에 적용됩니다. 값을 바꾸고 OK를 누르면 시간 순서로 재정렬됩니다.
  4. 표의 첫 행이 0 min이고 총 두 행 이상인지 확인합니다. 같은 시간의 점을 두 개 넣으면 실행 검증에서 중복 시간 오류가 나므로 하나를 수정하거나 삭제합니다.
  5. Save inputs로 전체 프로파일을 저장하거나 Run simulation으로 입력과 프로파일을 함께 저장하고 실행합니다.

예를 들어 120/200 → 840/200이면 시작 120분부터 840분까지 200°C로 유지되어 유지 시간은 720분입니다. 순간적인 계단 상승을 만들기 위해 같은 시간을 중복 입력할 수는 없습니다. 입력하려는 프로파일이 실제 어떤 시간 이력을 뜻하는지 이 두 제약을 기준으로 점검하십시오.

10. 중심 열전대 CSV와 보정 절차

Center thermocouple calibration은 측정 중심 온도와 계산 중심 온도의 차이를 줄이도록 두 변수, Calibrated k scale과 Calibrated h를 동시에 맞춥니다. 보정은 항상 PSD(T) 모델을 기반으로 수행하며, 현재 k_eff mode가 Manual이어도 보정 계산은 Calibrated로 전환해 수행합니다. 공간 격자와 열 해석기는 최종 해석과 동일하고, 보정 반복 중에는 산소 계산과 3D 스냅샷 저장을 생략합니다.

  1. 측정 실험에 맞는 치수, 재료, 밀도, 입도, 초기 온도, 오븐 프로파일 및 격자를 입력합니다. 측정값과 프로파일은 같은 시작 시점을 사용해야 합니다.
  2. CSV를 쉼표로 구분하여 준비합니다. 권장 헤더는 time_min,center_C입니다. 최소 다섯 개의 유효 숫자 행이 필요하고 그중 최소 다섯 행이 0~프로파일 종료 시간 안에 있어야 합니다.
  3. Load TC CSV를 눌러 파일을 선택합니다. Loaded 표시에서 점 수와 시간 범위를 확인합니다. 파일 인코딩은 utf-8-sig, cp949, utf-8 순으로 시도합니다.
  4. Calibrated k scale과 Calibrated h의 시작값을 확인합니다. 최적화 범위는 scale 0.10~10.0, h 1~100 W/m²K이므로 시작값도 이 범위 안에 둡니다.
  5. Fit k scale + h를 누릅니다. 상태에 평가 횟수, RMSE, 배율, h가 표시됩니다. 중단이 필요하면 Stop을 누릅니다.
  6. 완료 후 자동 갱신된 두 값과 Calibrated 모드를 확인합니다. 보정 완료는 최종 3D 결과 생성과 별개이므로 Run simulation을 다시 눌러 최종 결과를 만듭니다.

격자를 늘리면 공간 셀 수뿐 아니라 안정성 시간 간격도 달라져 실행 시간이 크게 증가할 수 있습니다. Max Δt를 키워도 안정성 조건이 더 작으면 계산은 빨라지지 않습니다. 산소를 켜면 산소 확산 안정성도 시간 간격에 반영됩니다. 서로 다른 조건을 비교할 때는 변경한 항목과 함께 실제 사용 Δt를 확인하십시오.

3D 스냅샷은 최대 300프레임과 약 384 MiB의 필드 저장 목표를 기준으로 간격이 자동 확대될 수 있습니다. 이는 3D 저장 주기만 조절하며 사용자가 요청한 계산 격자를 줄이지 않습니다. 실제 저장 간격과 프레임 수는 요약에 표시됩니다. 3D 화면에서도 큰 격자는 표시 점만 줄이며 중심·최소·최대값은 전체 저장 필드로 계산합니다.

  1. Run simulation 후 상태가 Running인지 확인합니다. Stop은 중단 요청을 보낸 뒤 계산 루프가 이를 확인하면 종료합니다.
  2. 중단되거나 오류가 발생한 실행은 새로운 완료 결과로 채택되지 않습니다. 기존 완료 결과가 남아 있을 수 있으므로 Export CSV 전에 상태를 확인하십시오.
  3. Save inputs는 현재 화면 입력과 전체 프로파일을 저장하고 Load saved는 저장한 입력을 복원합니다. 실행 전 검증을 통과한 조건은 자동 저장되며 보정 완료 값도 저장됩니다.
  4. 통합 모드에서는 사용자별 공통 파일 BJT_Tools/settings.json의 오븐 입력 영역에 저장합니다. 언어·숫자 입력·체크 상태·전체 프로파일·불러온 열전대 수치가 포함됩니다. ‘기본값으로 되돌리기 / Reset defaults’는 확인 후 내장 기본값을 화면에 복원합니다. 원본 전용 스크립트를 따로 실행하면 기존 .sic_buildbox_thermal_gui_settings.json 저장 방식을 사용합니다.
참고

설정 저장은 결과나 3D 필드 저장을 뜻하지 않습니다. 다음 실행에서 복원되는 것은 입력 조건입니다. 재현할 계산의 결과 CSV는 별도로 저장하십시오. 프로그램 종료 시에도 현재 입력 저장이 수행되므로 여러 조건을 비교할 때는 각 실행의 조건 기록을 함께 보관하는 것이 좋습니다.

실제 시간 간격은 열전도·금속판·열경계·산소 농도 확산의 안정성 조건 중 가장 작은 값과 요청 상한을 사용합니다. 계산된 작은 시간 간격을 임의의 최솟값으로 키우지 않습니다. 작은 형상이나 매우 촘촘한 격자에서는 계산 횟수가 많아질 수 있습니다. NaN·무한대·정수가 아닌 격자·절대영도 이하의 온도 등은 계산 전에 거부합니다.

참고

열전달의 보존형 유한체적 계산, 금속판 결합, 대류·복사 및 바닥 공기층 모델은 유지했습니다. 입도 기반 유효 열전도율·공극 길이·대류계수는 근사 모델이므로 실제 충전 밀도와 중심 열전대 자료로 보정하고, 격자·시간 간격을 바꾼 민감도를 함께 확인하세요.

12. 그래프·3D 결과 읽기

Temperature history는 시간[h]에 따른 오븐과 분말의 중심·표면·체적 평균 및 범위 등을 표시합니다. 그래프의 선 가까이에 마우스를 두면 해당 표본의 값을 확인할 수 있습니다. 중심은 기하학적 중심을 둘러싼 셀의 평균으로, 각 축의 격자 수가 홀수면 한 셀, 짝수면 인접 두 셀을 사용하므로 항상 단일 셀 값은 아닙니다.

surface_avg는 여섯 분말 경계면 각각의 셀 평균을 구한 뒤 여섯 값을 단순 평균한 진단값입니다. 면적 가중 평균이 아니므로 X·Y·Z의 길이가 다른 경우에도 모든 면이 같은 가중치를 가집니다. volume_avg는 전체 분말 셀 평균, min/max는 전체 분말 셀의 최소·최대값이며 금속판 온도와 구분됩니다.

  2. 슬라이더를 끌어 특정 저장 시점으로 이동합니다. Play를 누르면 시간 순서로 재생되고 Pause로 멈춥니다. 두 3D 화면은 각각 조작합니다.
  3. 마우스로 3D 그림을 끌어 회전합니다. 시간 프레임을 바꾸어도 선택한 시점 각도가 유지됩니다.
  4. 색상 막대의 단위와 프레임 표시 시간을 함께 읽습니다. 온도는 실행 전체의 고정 색상 범위, 산소는 해당 실행의 농도 범위를 사용합니다.
  5. 화면의 display 표시로 표시 셀 수와 전체 셀 수를 구분합니다. 점을 줄여 그린 화면이므로 시각적 밀도를 계산 격자의 실제 크기로 판단하지 않습니다.

중심 산소가 외부 농도와 같게 한 시간 유지되면 누적 노출은 1 air-equivalent h입니다. 예를 들어 외부의 절반 농도를 두 시간 유지해도 같은 값이 될 수 있습니다. 이 적분량은 농도 노출 지표이며 어떤 온도에서 어떤 화학 반응이 일어났는지는 포함하지 않습니다.

14. 작업 예시 — 가열 비교와 산소 유입

확인 사항

다음 두 시나리오는 메뉴·단위·결과 확인 순서를 익히는 조작 연습입니다. 치수, 물성, 프로파일 및 CSV 수치는 실제 생산 조건으로 검증되지 않았습니다. 특정 도달 온도나 도달 시간을 예상 결과로 보장하지 않습니다.

예시 A. 일정 k_eff 조건에서 가열 지연 확인

  1. Reset defaults 후 X=100, Y=120, Z=80 mm를 입력합니다. Material=SUS304, Side=3 mm, Bottom=5 mm, Under-plate gap=40 mm, Top is open=켜짐으로 둡니다.
  2. Bed density=1.700 g/cc, True density=3.210 g/cc, cp=750 J/kgK로 둡니다. k_eff mode=Manual, Manual k_eff=0.60 W/mK를 지정합니다. Convection h=12, Effective emissivity=0.75, Initial bed temp=25°C를 사용합니다.
  3. Enable O₂ diffusion-only simulation을 끕니다. Grid nx/ny/nz=8/10/8, Max Δt=10 s, Output interval=60 s, 3D snapshot interval=5 min을 입력합니다.
  4. Oven profile을 0/25, 60/120, 120/120, 180/180, 240/180, 300/80으로 작성합니다. 시간은 모두 시작 후 누적 min입니다.
  5. Run simulation 완료 후 Temperature history에서 oven과 center의 차이를 읽습니다. 3D temperature field의 60·180·300분 부근 프레임을 선택해 내부 온도 편차가 어떻게 변하는지 확인합니다.
  6. Export CSV로 exercise_A_manual.csv를 저장합니다. 비교가 필요하면 k_eff만 바꾸어 다시 실행하고 다른 이름으로 저장합니다. 두 실행의 실제 Δt와 나머지 입력을 함께 확인합니다.

예시 B. 초기 산소가 낮은 분말층의 순수 유입 관찰

  1. Reset defaults 후 X/Y/Z=80/80/60 mm, SUS304 측벽 3 mm·바닥 5 mm·하부 간격 40 mm, 상부 열적 개방으로 설정합니다. 밀도와 분말 물성은 내장 기본값을 사용하고 k_eff mode=PSD estimate를 선택합니다.
  2. D10/D50/D90=40.6/65.4/105.0 µm를 확인합니다. 산소 해석을 켜고 Ambient O₂=20.95 vol%, Initial pore O₂=0 vol%를 입력합니다. 이 초기값은 산소 부족 상태에서 출발하는 연습 가정입니다.
  3. D_air=2.05e-5 m²/s, D temperature exponent=1.75, Tortuosity model=Bruggeman, Knudsen correction=켜짐으로 둡니다. O₂ access의 Top만 켜고 Sides는 끄며 Bottom은 비활성 상태를 유지합니다.
  4. 격자 8/8/6, Max Δt=10 s, Output interval=30 s, 3D snapshot interval=2 min으로 설정합니다. 오븐 프로파일은 0/25, 30/100, 90/100, 120/25를 입력합니다.
  5. Preview O₂ diffusivity로 확산계수를 확인한 뒤 실행합니다. O₂ history에서 상부 층과 중심이 외부 농도로 접근하는 과정을 보고, 3D O₂ field에서 농도 분포의 시간 변화를 확인합니다.
  6. O₂ summary의 50/90/95/99% 도달시간과 air-equivalent h를 읽고 exercise_B_ingress.csv를 저장합니다. 동일 조건에서 Initial pore O₂만 20.95로 바꾸어 재실행하면 균일 농도가 유지되는 모델 특성을 확인할 수 있습니다.

두 예시를 연속 실행하면 두 번째 입력이 마지막 저장 조건이 됩니다. 첫 번째 결과와 조건을 다시 사용할 예정이면 첫 결과 CSV를 먼저 저장하고 입력값을 기록해 두십시오. 예시 B의 산소 증가는 반응에 의한 소모가 없는 확산 결과이므로 바인더 처리 완료 여부와 직접 대응시키지 않습니다.

16. 입력값 자동 저장과 복원

통합 프로그램을 정상 종료하면 입력값을 사용자별로 저장합니다. 다음 실행에서 이 도구를 열 때 저장한 값을 복원하며, 열지 않은 탭의 이전 설정도 유지합니다. 계산이나 파일 처리를 자동으로 시작하지 않습니다.

이 도구의 통합 설정이 아직 없으면 첫 실행에 1.6.2의 기존 저장 설정을 읽어 이어서 사용합니다. 이후에는 공통 설정에 저장하며, 기존 파일은 수정하거나 삭제하지 않습니다. 공통 설정에 이 도구의 값이 있으면 그 값을 우선합니다.

  • 저장 대상: 입력 숫자·문자·선택·체크 상태·원본 경로·입력 목록과 작업에 필요한 배치·프로파일. 이미지 변환의 사용자 픽셀·DPI와 오븐의 언어·불러온 열전대 수치도 포함합니다.
  • 계산 결과·로그·진행 중 작업·이미지와 메쉬 원본은 설정에 저장하지 않습니다. 결과는 필요한 CSV·JSON·HTML·STL 등으로 따로 저장합니다.
  • 저장 위치: Windows는 %LOCALAPPDATA%\BJT_Tools\settings.json. Linux는 $XDG_CONFIG_HOME/BJT_Tools/settings.json 또는 ~/.config/BJT_Tools/settings.json입니다.
  • 원본이나 변환 캐시를 이동·삭제하면 복원한 경로를 사용할 수 없을 수 있습니다. 복원된 입력과 실제 파일을 확인한 뒤 실행합니다.
  • 강제 종료·프로세스 종료·전원 차단 직전의 변경은 정상 종료 저장에 포함되지 않을 수 있습니다. 저장 실패 시 경고·오류 기록을 확인하고 기존 설정을 보존합니다.
참고

손상된 설정은 기본값으로 시작하며, 다음 저장 시 손상 파일을 settings.json.corrupt-시각 이름으로 보관합니다. 복원할 수 없는 숫자형 항목은 기본값을 사용할 수 있으므로 실행 전 입력을 확인하세요.
