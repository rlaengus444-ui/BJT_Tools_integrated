IR 피드백 제어

이미지 회복제어 Excel과 최신 외부 IR 모듈을 통합한 도구

문서 1.02026.11.17한국어 · 오프라인판

목차

  1. 시작하기
  2. 내장 계산시트와 다른 알고리즘
  3. 이미지 입력과 교체
  4. 운전과 기록 저장

시작하기

  1. Microsoft Excel 데스크톱이 설치된 Windows PC에서 통합프로그램을 실행합니다. IR 피드백 제어 도구를 엽니다.
  2. 기본 선택은 이미지 회복제어 (내장 Excel)입니다. 별도 계산시트 파일을 찾아 지정할 필요가 없습니다. M1 또는 S3와 실행 중인 BinderJet 창을 선택합니다.
  3. 슬라이싱 이미지 탭에서 중앙 반경(mm)을 입력하고 ZIP 또는 이미지 전체 선택으로 분석합니다. 기본 흰색 분사·X/Y DPI 400이며 변경할 수 있습니다.
  4. 목표 온도와 최대 IR 출력을 확인하고 연결을 누릅니다. 이전 단독 IR 프로그램은 종료합니다. 연결 준비에는 원본 시트의 수식 검사와 Excel 초기화 시간이 필요합니다.
  5. 작업 시작 로그·새 완료 CSV·AUTO 상태·설정 확인 후 기존 제어 절차로 적용합니다. 도구를 열거나 설정을 복원하는 것만으로 제어를 시작하지 않습니다.
참고

최종 제어 알고리즘 승인과 실제 장비 적용은 보류 상태입니다. Windows 모의 검증은 센서·PLC·실제 램프 출력 검증이 아닙니다. M2는 현재 지원하지 않습니다.

내장 계산시트와 다른 알고리즘

원본 01_IR_이미지기반_회복제어_2026.10.28.xlsx를 수식 변경 없이 포함합니다. 이미지 데이터는 참고 표시뿐 아니라 기존 회복제어 수식에 사용됩니다. 계산시트 바이트 해시를 검사한 뒤 격리 복사본으로 열고, 다음 층도 열린 Excel 작업에서 계산합니다. 매 층 Excel을 다시 시작하지 않습니다. 내장 시트는 데스크톱 Excel이 필요하며 Excel이 없거나 시트가 손상된 경우 다른 알고리즘으로 자동 전환하지 않습니다.

시트수동 테스트
층 / 온도 / 현재 실제 IRA13 / B13 / C13
계산 IR / 목표 온도D13 / B5

기본 알고리즘 또는 Excel 수식 파일을 선택할 수도 있습니다. 사용자 Excel 경로와 셀 주소, 기본 알고리즘 JSON 경로는 각각 따로 보존됩니다. 내장 시트 선택에서는 셀 주소를 수정하지 않습니다. 슬라이싱 탭의 기존 참고용 시트 저장 / 사용은 이전 참고용 템플릿이며 내장 이미지 회복제어와 다릅니다.

이미지 입력과 교체

이미지는 수동 ZIP 또는 다중 파일 선택으로 입력합니다. 프린터 첫 탭 경로의 자동 불러오기는 제공하지 않습니다. 연결 중에도 새 이미지 분석 후 교체를 예약할 수 있습니다. 다른 작업을 확인한 경우 현재 작업에 이미지 적용으로 확인합니다. 이미지 중앙 분석은 계획된 분사 패턴이며 센서 실제 위치·분사 실행·건조 완료를 증명하지 않습니다.

종료 시 선택 경로와 반경·DPI·층 대응 등 입력을 저장하지만 분석 결과나 작업 권한은 복원하지 않습니다. 다시 실행하면 이미지를 다시 분석해야 합니다. 이전 HWND/PID·세션·실행 상태는 복원하지 않습니다.

운전과 기록 저장

최신 IR 모듈 2026.11.12-layer-validity.1의 작업·층 유효성, 연결 유지·자동복구, 컨트롤러 PID 재검색, 출력 상한, Save 확인 절차를 유지합니다. 최대 출력은 연결 중에도 상한 적용으로 바꿀 수 있으며 낮은 상한은 새 층마다 최대 5%p씩 낮춰 도달합니다. 경과 시간만으로 계산을 만료시키지 않지만 실제 작업·관측·설정이 달라지면 이전 계산은 저장하지 않습니다.

그래프는 최근 100층을 표시하며 전체보기와 전체 CSV 저장을 제공합니다. 연결 해제·작업 전환·프로그램 종료 때 CSV와 온도 PNG·IR PNG를 자동 저장합니다. EXE 옆 records 폴더를 사용하고 쓰기가 불가능하면 %LOCALAPPDATA%/IRFeedback/records를 사용합니다. 상태 기록에 전체 경로를 표시합니다.

통합 창을 닫으면 IR·이미지 작업과 소유한 Excel 정리, CSV·PNG 저장 완료를 기다립니다. 저장 실패 때 폴더 선택을 취소하면 기록을 메모리에 남기고 창을 유지합니다. 다른 도구 탭으로 전환해도 IR 연결은 유지합니다. 현재 작업 중단 버튼은 IR 연결 해제를 요청하며 히터 ON/OFF나 이전 출력 복원을 실행하지 않습니다.
