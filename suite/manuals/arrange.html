1. 제품 개요와 작업 흐름

이 도구는 이미지 폴더 또는 STL을 배치 항목으로 등록하고, 위치·회전·출력 포함 여부를 지정하여 하나의 슬라이싱 이미지 세트로 합성합니다. 이미지 폴더는 각 폴더의 자연 정렬 순서가 같은 레이어끼리 연결됩니다. STL은 mm 단위로 해석하여 현재 DPI와 층두께로 내부 슬라이싱한 뒤 같은 방식으로 배치합니다.

  1. 최종 해상도와 DPI, STL을 사용할 경우 층두께를 먼저 설정합니다.
  2. 폴더 또는 STL을 추가하고 필요한 수만큼 복제합니다.
  3. X/Y와 회전을 조정하고 여러 레이어를 미리보기합니다.
  4. 합성 방식·출력 길이·출력 폴더를 확인한 뒤 전체 레이어를 합성합니다.
참고

배치는 원본 파일을 편집하지 않습니다. 복제는 같은 원본을 사용하는 독립 배치 항목을 만드는 기능입니다. 출력 폴더의 같은 이름 PNG는 합성 시 덮어쓰므로 작업별 새 폴더를 사용하면 결과를 구분하기 쉽습니다.

참고

통합판 1.4 화면: 좌측의 파일·배치 / 미리보기 / 조작 안내 탭을 전환하여 목록·좌표, 레이어·투명도, 단축키 안내를 엽니다. 원래 입력값·버튼·단축키는 유지합니다. 창 폭이 좁으면 상단 캔버스·DPI 설정을 두 줄로 배치하며, 하단 출력·전체 레이어 합성·취소는 항상 화면 공간을 먼저 확보합니다.

2. 처음 사용하는 분을 위한 빠른 시작

  1. 상단 최종 해상도에 가로·세로 픽셀 수를 입력하고 [캔버스 적용]을 누릅니다. 입력값은 1 이상의 정수여야 합니다.
  2. DPI X/Y를 입력합니다. 이미지 폴더의 픽셀 수는 DPI를 바꿔도 확대·축소되지 않습니다.
  3. [폴더 추가]로 이미지가 직접 들어 있는 폴더를 선택합니다. 추가된 항목은 기본 X=0, Y=0에서 시작합니다.
  4. 왼쪽 목록에서 항목을 선택한 뒤 X/Y를 입력하고 Enter를 누르거나 다른 곳을 클릭하여 적용합니다. 중앙 이미지도 드래그할 수 있습니다.
  5. [미리보기]의 ◀/▶ 또는 레이어 번호로 첫 층·중간 층·마지막 층을 점검합니다.
  6. 합성은 max, 길이는 max를 시작점으로 사용하되 실제 목적에 맞게 선택합니다. 하단 출력 폴더를 확인합니다.
  7. [전체 레이어 합성]을 누르고 완료 창의 출력 수와 폴더를 확인합니다. 실제 출력 PNG도 열어 가장자리와 레이어 순서를 확인합니다.

화면 맞춤은 캔버스를 보기 좋은 배율로 보여주며 100%는 표시 배율을 1배로 바꿉니다. 이 두 버튼은 출력 해상도나 배치 좌표를 바꾸지 않습니다.

3. 입력 데이터와 레이어 규칙

항목지원 및 처리 규칙
이미지 폴더PNG, BMP, TIF, TIFF, JPG, JPEG, WEBP. 선택 폴더 바로 아래 파일만 수집하며 하위 폴더는 탐색하지 않습니다.
파일 정렬이름에 포함된 숫자를 숫자로 비교하는 자연 정렬입니다. 예: 1.png → 2.png → 10.png. 파일명이 숫자만으로 되어 있을 필요는 없습니다.
레이어 대응첫 번째 이미지들끼리, 두 번째 이미지들끼리 합성합니다. 폴더 사이에서 같은 파일명을 찾는 방식은 아닙니다.
색상·투명도이미지는 8비트 그레이스케일로 변환합니다. 알파 채널이 있는 이미지는 투명 영역을 검정 배경에 합성한 뒤 변환합니다.
STL.stl 파일. 좌표 단위 mm, 수평 단면. 모델 최소점을 원점으로 이동하고 전체 XY 바운딩 박스를 모든 층에 공통 적용합니다.

폴더를 목록이나 캔버스로 드래그하여 추가할 수 있습니다. 캔버스에 놓으면 놓은 지점의 캔버스 좌표를 기준으로 배치됩니다. 여러 입력을 한 번에 놓으면 순차적으로 20 px씩 어긋나게 배치되어 겹친 항목을 구분할 수 있습니다. 드래그앤드롭을 사용할 수 없는 환경에서는 [폴더 추가] 또는 [STL 추가]를 사용합니다.

확인 사항

폴더에 레이어와 관계없는 지원 이미지가 섞여 있으면 정렬과 레이어 수에 포함됩니다. 입력 폴더를 확인하고, 로딩 후 표시되는 파일 수와 현재 파일명을 검사하십시오. 로딩 뒤 원본 파일을 이동하거나 삭제하면 미리보기·합성이 실패할 수 있습니다.

5. 배치·회전·미리보기 조작

회전은 이미지 중심을 유지하며 적용합니다. 회전 후 바운딩 박스 크기가 달라지므로 X/Y가 자동으로 바뀔 수 있습니다. 정확한 좌상단 위치가 필요하면 회전을 먼저 정한 다음 X/Y를 입력하십시오. 임의 각도 회전은 최근접 보간과 검정 배경을 사용하며, STL 배치에서도 Z축 회전만 적용합니다.

참고

미리보기는 축소 이미지와 표시용 투명도를 사용합니다. 실제 저장은 원본 해상도에서 합성하므로 확대 시 화면의 밝기·테두리 인상이 결과와 다를 수 있습니다. 합성 모드 선택에 따른 정확한 겹침 픽셀은 저장된 PNG에서 확인합니다.

6. 작업 예제 ① 같은 이미지 세트 3개 배치

예제 조건: Part_A 폴더에 1.png~120.png, 각 이미지가 400 × 600 px라고 가정합니다. 2000 × 2000 px 캔버스에 같은 세트를 세 개 배치하고 세 번째를 90° 시계방향으로 회전합니다.

  1. 최종 해상도 2000 × 2000을 적용하고 Part_A를 [폴더 추가]로 등록합니다.
  2. 첫 배치 X=100, Y=100을 입력합니다. 범위는 X 100~499, Y 100~699입니다.
  3. Ctrl+D로 복제한 두 번째 배치를 X=600, Y=100으로 지정합니다.
  4. 다시 Ctrl+D로 세 번째를 만들고 Alt+휠 위 방향 18칸으로 90°를 맞춥니다. 목록의 회전=90°를 확인한 뒤 X=1100, Y=100을 다시 입력합니다.
  5. 세 번째의 회전 후 크기는 600 × 400 px이며 X 1100~1699, Y 100~499에 놓입니다. 캔버스 2000 × 2000 안에 모두 들어갑니다.
  6. 합성=max, 길이=max, 세 항목 모두 출력에 포함을 선택하고 새 출력 폴더에 합성합니다. 결과는 120장의 2000 × 2000 PNG입니다.
참고

3개 배치는 같은 원본 레이어를 공유하지만 각자의 위치·회전·포함 여부는 독립적입니다. 예제 좌표는 px이며, 400 dpi에서 100 px는 약 6.35 mm에 해당합니다. 원본 픽셀 크기가 다르면 배치 범위를 다시 계산하십시오.

7. 작업 예제 ② STL과 이미지 세트 혼합

예제 조건: XY 크기 25.4 × 12.7 mm, Z 높이 10 mm인 STL과 80층 이미지 세트를 함께 배치합니다. DPI X/Y=400, STL 층두께=0.1 mm라면 STL의 공통 이미지 크기는 400 × 200 px, 층수는 100층입니다.

  1. DPI 400/400과 STL 층두께 0.1을 먼저 입력한 뒤 [STL 추가]를 누릅니다. 슬라이싱 완료를 기다립니다.
  2. 목록에서 STL을 선택해 모델 크기, 100장, 0.1 mm, 400×400 DPI 표시를 확인합니다.
  3. 80층 이미지 폴더를 추가하고 두 항목을 원하는 좌표로 옮깁니다. 실제 제작에서 결합할 경우 양쪽 레이어의 물리 높이 기준도 별도로 맞아 있어야 합니다.
  4. 길이=max이면 100장을 출력합니다. 81~100층에는 이미지 폴더 배치가 없고 STL만 합성됩니다. 길이=min이면 80장을 출력합니다.
  5. 설정 후 STL 층두께를 0.2로 바꾸었다면 해당 STL을 삭제하고 다시 추가합니다. 기존에 읽은 STL은 자동 재슬라이싱되지 않으며 설정 불일치 시 합성을 막습니다.

STL은 층 중앙 높이에서 단면을 만듭니다. 마지막 중심이 모델 높이를 넘으면 상단 바로 아래에서 자르며, 단면이 없는 층은 검정 이미지가 됩니다. 같은 파일과 같은 DPI·층두께의 내부 캐시가 있으면 재사용합니다. 메시의 구멍·중첩은 폐곡선의 짝홀수 규칙으로 래스터화합니다.

8. 합성 규칙·출력·클리핑

규칙결과
max겹친 픽셀 80과 200의 결과는 200. 흰색 재료/검정 배경의 이진 이미지에서는 OR 합성에 해당합니다.
overwrite나중에 등록된 배치가 앞의 영역을 덮습니다. 검정 픽셀도 덮으므로 앞 배치의 흰 영역을 지울 수 있습니다.
캔버스 밖출력 캔버스를 벗어난 부분은 잘립니다. 음수 좌표도 허용하며, 완전히 밖에 있는 배치는 출력 픽셀을 만들지 않습니다.
빈 영역0(검정)으로 저장합니다. 해당 층이 없는 짧은 세트는 그 층에서 건너뜁니다.
파일명·형식입력 이름과 관계없이 1.png, 2.png, 3.png… 순번, 8비트 그레이스케일 PNG. 최종 해상도와 DPI X/Y를 사용합니다.

자동 출력 폴더는 입력 이름의 공통부에 _합성을 붙여 첫 입력의 부모 폴더 아래에 제안합니다. 한 폴더 Part_A만 사용하면 그 옆의 Part_A_합성이 됩니다. [선택] 또는 직접 입력으로 경로를 바꾸면 이후 입력 추가·삭제로 자동 변경하지 않습니다. [자동]은 입력 구성으로 경로를 다시 제안합니다. 지정 폴더가 없으면 합성 시작 시 생성합니다.

확인 사항

기존 같은 이름 파일에 대한 별도 덮어쓰기 확인이나 자동 백업은 없습니다. 기존 출력 폴더에 더 많은 레이어가 있었다면 새로 만들지 않은 뒤쪽 파일은 남을 수 있습니다. 결과 층수 확인과 이전 결과 혼동 방지를 위해 빈 출력 폴더를 사용하십시오.

9. 진행 확인·취소·작업 보존

합성 중 하단에 진행률, 완료 수, 원본 레이어, 출력 파일명이 표시됩니다. 여러 레이어를 병렬 처리하므로 화면에 보이는 완료 파일명이 항상 순서대로 증가하지는 않습니다. 시작할 때의 배치·설정 사본을 사용하므로 그 뒤 화면 배치를 바꾸어도 이미 시작한 합성에는 반영되지 않습니다.

  1. 중단하려면 하단 [취소] 또는 통합 프로그램 상단 [현재 작업 중단]을 누릅니다.
  2. 현재 실행 중인 레이어 합성·저장이 끝나고 대기 작업이 취소될 때까지 기다립니다. 즉시 모든 파일 처리가 멈추는 방식은 아닙니다.
  3. 완료되어 저장된 PNG는 남습니다. 취소는 출력 폴더를 삭제하거나 이전 파일로 복구하지 않습니다.
  4. 완성된 전체 세트가 필요하면 빈 폴더를 지정하여 처음부터 다시 실행하고 완료 메시지의 출력 수를 확인합니다.
참고

STL 가져오기에는 별도의 슬라이싱 취소 버튼이 없습니다. 합성용 취소는 이미 진행 중인 STL 내부 슬라이싱을 중단시키지 않습니다. 통합 프로그램 종료 절차에서는 진행 중인 작업이 정리될 때까지 기다립니다.

10. 문제 해결과 용어

증상·메시지확인 방법
이미지 파일을 찾지 못했습니다이미지가 선택 폴더 바로 아래에 있는지와 지원 확장자를 확인합니다.
선택 배치가 보이지 않음출력에 포함, 현재 층의 파일 유무, X/Y, 캔버스 범위를 확인한 뒤 화면 맞춤을 누릅니다.
STL 설정이 현재 값과 다름현재 DPI·층두께를 확정한 뒤 해당 STL을 삭제하고 다시 추가합니다.
출력 모서리가 잘림회전 후 바운딩 박스와 X/Y를 확인하고 캔버스를 늘리거나 안쪽으로 이동합니다.
합성 실패원본 경로·파일 읽기 권한·출력 폴더 쓰기 권한·저장 공간을 확인합니다. 오류 상세의 첫 실패 파일을 확인합니다.
STL 해상도가 너무 큼STL 단위가 mm인지와 DPI를 확인합니다. 모델 크기·DPI가 지나치면 이미지 메모리 제한으로 거부합니다.
다음 실행 때 배치가 사라짐통합 프로그램에서는 해상도·DPI·STL 층두께뿐 아니라 입력 원본 경로와 현재 배치·순서도 정상 종료 시 저장합니다. 원본 이미지·STL·변환 캐시 파일 자체는 설정에 포함되지 않으므로 파일 위치를 유지하고, 복원 뒤 미리보기와 출력 조건을 확인하세요.
  • 캔버스: 최종 출력 이미지의 픽셀 영역입니다.
  • 배치: 한 이미지 세트 또는 STL 슬라이스의 위치·회전·포함 상태를 가진 항목입니다.
  • 자연 정렬: 이름 속 숫자를 크기로 비교하여 2를 10보다 앞에 놓는 정렬입니다.
  • DPI: 1인치(25.4 mm)당 픽셀 수입니다. STL 변환의 픽셀 간격은 25.4÷DPI mm입니다.
  • 클리핑: 캔버스 밖의 이미지 부분을 출력에서 잘라내는 처리입니다.
  • 바운딩 박스: 회전된 이미지를 모두 감싸는 사각 영역이며 X/Y는 그 좌상단을 나타냅니다.

11. 입력값 자동 저장과 복원

통합 프로그램을 정상 종료하면 입력값을 사용자별로 저장합니다. 다음 실행에서 이 도구를 열 때 저장한 값을 복원하며, 열지 않은 탭의 이전 설정도 유지합니다. 계산이나 파일 처리를 자동으로 시작하지 않습니다.

이 도구의 통합 설정이 아직 없으면 첫 실행에 1.6.2의 기존 저장 설정을 읽어 이어서 사용합니다. 이후에는 공통 설정에 저장하며, 기존 파일은 수정하거나 삭제하지 않습니다. 공통 설정에 이 도구의 값이 있으면 그 값을 우선합니다.

  • 저장 대상: 입력 숫자·문자·선택·체크 상태·원본 경로·입력 목록과 작업에 필요한 배치·프로파일. 이미지 변환의 사용자 픽셀·DPI와 오븐의 언어·불러온 열전대 수치도 포함합니다.
  • 계산 결과·로그·진행 중 작업·이미지와 메쉬 원본은 설정에 저장하지 않습니다. 결과는 필요한 CSV·JSON·HTML·STL 등으로 따로 저장합니다.
  • 저장 위치: Windows는 %LOCALAPPDATA%\BJT_Tools\settings.json. Linux는 $XDG_CONFIG_HOME/BJT_Tools/settings.json 또는 ~/.config/BJT_Tools/settings.json입니다.
  • 원본이나 변환 캐시를 이동·삭제하면 복원한 경로를 사용할 수 없을 수 있습니다. 복원된 입력과 실제 파일을 확인한 뒤 실행합니다.
  • 강제 종료·프로세스 종료·전원 차단 직전의 변경은 정상 종료 저장에 포함되지 않을 수 있습니다. 저장 실패 시 경고·오류 기록을 확인하고 기존 설정을 보존합니다.
참고

손상된 설정은 기본값으로 시작하며, 다음 저장 시 손상 파일을 settings.json.corrupt-시각 이름으로 보관합니다. 복원할 수 없는 숫자형 항목은 기본값을 사용할 수 있으므로 실행 전 입력을 확인하세요.
