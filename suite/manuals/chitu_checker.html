치투 오브젝트 검사

배치된 오브젝트의 삼각형 표면 간격을 검사하고 3D 배치로 확인하는 가이드

1. 검사 범위

CHITUBOX Basic 프로젝트의 배치 또는 같은 작업판 좌표로 내보낸 개별 STL을 읽고 오브젝트의 원본 삼각형 표면 사이 최단 거리를 검사합니다. 원본 파일은 수정하지 않습니다.

확인 사항

이 검사는 표면 간격만 판정합니다. 부피 겹침과 한 오브젝트가 다른 오브젝트 내부에 완전히 포함되는 경우는 검사하지 않으므로 제조 안전이나 일반적인 겹침 없음을 뜻하지 않습니다.

닫힌 입체, 비다양체, 면 방향과 양의 체적에 대한 형상 품질 판정은 수행하지 않습니다. 유한 좌표와 인덱스, 읽기 가능 여부 및 원본 표면 거리 계산에 필요한 조건은 확인합니다.

2. 빠른 시작

  1. 통합 프로그램에서 치투 오브젝트 검사를 엽니다.
  2. CHITUBOX 프로젝트 한 개 또는 같은 배치 좌표와 mm 단위를 유지한 개별 STL을 선택합니다.
  3. 최소 간격(mm)에 0 이상의 유한한 값을 입력하고 검사를 시작합니다.
  4. 표면 접촉·교차 위험, 간격 미달, 판정 불가 항목과 검사 범위를 확인합니다.
  5. 필요하면 3D 배치 보기와 JSON을 저장합니다. 입력이나 기준을 바꾸면 다시 검사합니다.
목차와 처음으로 ↑

3. 입력 형식과 좌표

지원되는 CHITUBOX Basic 바이너리 프로젝트 한 개, 배치를 유지한 개별 STL 파일 여러 개 또는 STL 폴더를 사용할 수 있습니다. 확장자만 바꾸어 형식을 변환할 수 없습니다. CTB/CTP와 별도 네이티브 서포트·래프트 블록은 지원하지 않습니다.

확인 사항

서포트까지 검사하려면 CHITUBOX에서 서포트가 포함된 메쉬를 개별 STL로 내보내고 모든 STL의 공통 작업판 좌표를 유지하세요. 모델별 원점 재설정이나 자동 중앙 정렬은 배치 비교 결과를 바꿉니다.

목차와 처음으로 ↑

4. 표면 거리와 판정

거리는 원본 삼각형 표면 사이의 부호 없는 최단 거리입니다. 판정은 화면에 반올림한 숫자가 아닌 원래 수치와 접촉 허용오차를 사용합니다.

조건결과
거리 ≤ 접촉 허용오차FAIL · 표면 접촉/교차 위험
그 외 거리 + 허용오차 < 요구 간격FAIL · 표면 간격 미달
그 외표면 간격 조건 충족
읽기·계산 불가 또는 중단판정 불가 또는 검사 미완료

양의 표면 거리가 요구 간격을 충족해도 내부 포함에 따른 부피 겹침은 판정하지 않습니다. 경계 상자가 겹치는 양의 거리 쌍에도 내부 포함 여부 미검사 안내를 표시합니다. 경계 상자 중첩 자체는 내부 포함의 증거가 아닙니다.

목차와 처음으로 ↑

5. 결과 해석

완료 여부는 표면 간격 계산의 완료를 뜻합니다. 결과 화면과 오류 목록을 함께 확인하고, 판정 불가나 중단이 있으면 해당 입력과 원인을 확인한 뒤 다시 검사하세요.

오브젝트는 이름과 인덱스로 구별합니다. 실제 측정한 표면 거리와 최근접점을 확인하고, 거리를 측정하지 못한 쌍은 미판정으로 확인합니다. 표면 간격 조건 충족은 체적 겹침이 없다는 뜻이 아닙니다.

화면은 소수 둘째 자리까지 표시하며 아주 작은 0이 아닌 값은 과학적 표기로 표시합니다. 계산과 JSON 저장에는 원래 정밀도를 사용합니다.

목차와 처음으로 ↑

6. 3D 배치 보기

배치보기에서 오브젝트와 문제 쌍을 확인합니다. 표시 예산 때문에 일부 표면은 축소된 미리보기나 외곽 상자로 표시될 수 있습니다. 이는 화면 표현이며 검사에 사용한 원본 표면이나 저장된 원본 파일을 바꾸지 않습니다.

확인 사항

3D 미리보기의 모양만으로 접촉·간격을 측정하거나 내부 포함을 판정하지 마세요. 수치와 검사 범위를 결과에서 확인하세요.

목차와 처음으로 ↑

7. 결과 저장과 원본 보호

JSON은 검사 범위, 표면 거리, 판정과 오류 등 계산 결과를 원래 정밀도로 저장합니다. HTML은 오프라인 배치 보기입니다. 입력 파일을 수정하지 않으며, 결과를 저장할 때 별도 경로를 선택하세요.

검사 범위를 나타내는 inspection_scope와 체적 겹침 미검사 여부를 확인하세요. 값이 없거나 계산되지 않은 거리와 0인 거리를 혼동하지 마세요.

목차와 처음으로 ↑

8. 진행과 중단

검사 중에는 진행 상태를 확인할 수 있으며 중단을 요청할 수 있습니다. 중단되거나 거리 계산이 실패한 검사는 완료된 결과로 간주하지 마세요.

9. 오류와 제한

상황확인할 점
프로젝트 형식 오류지원되는 Basic 프로젝트인지, 별도 서포트·래프트 블록이 있는지 확인하고 필요하면 배치 유지 STL로 내보냅니다.
표면 거리 판정 불가파일 읽기 오류, 비유한 좌표, 잘못된 인덱스 또는 거리 계산 조건을 확인합니다.
양의 거리이지만 경계 상자 중첩표면 거리는 측정했으나 내부 포함 여부는 검사하지 않습니다. 별도 방법으로 확인합니다.
화면이 단순하게 표시됨축소 미리보기 또는 외곽 상자 여부를 확인합니다. 판정은 원본 표면을 기준으로 합니다.
목차와 처음으로 ↑

10. 입력값 저장

통합 프로그램을 정상 종료하면 입력 설정을 사용자별로 저장하고 다음 실행에서 복원할 수 있습니다. 복원은 검사를 자동으로 실행하지 않습니다. 결과와 원본 파일은 별도로 보관하고 검사 전에 경로와 기준을 다시 확인하세요.
