모델 자동 배치 · BJT 1.10.1

1. 파일과 배치 조건

  1. 모델 자동 배치 탭에서 STEP/STP/STL을 추가하거나 끌어 놓습니다. STL 단위는 추가 전에 mm/cm/m/in 중 선택합니다.
  2. 수량 칸을 두 번 눌러 모델별 수량을 입력합니다. 배치 설정에서 빌드 X/Y/최대 Z, 모델 간격, XY 벽 간격과 계산 시간을 지정합니다.
  3. 내장 정책 사용은 기본 켬입니다. 정책 1차 배치 후 기존 알고리즘으로 개선하며 수량이 같으면 더 낮은 유효 해를 유지합니다.
  4. 계산 중 배치 수량·비율, 경과 시간과 남은 탐색 한도를 확인합니다. 정밀 탐색 추가 시간을 포함한 최대 탐색 한도이며 조기 종료될 수 있습니다. 입력 준비·XY 정렬·최종 검증 시간은 별도로 표시합니다.
  5. 배치 계산과 검증이 끝나면 탭 하단의 CHITUBOX 프로젝트 저장을 눌러 .chitubox 파일을 저장합니다. CHITUBOX에서 배치 계산에 사용한 것과 같은 빌드박스 크기를 선택하세요. STL·좌표·보고서 저장도 하단에서 선택할 수 있습니다.

2. 형상과 검증

  • 여러 솔리드가 들어 있는 STEP은 원본 파일을 유지하며 각 바디의 재료 영역을 합친 뒤 검사합니다. 떨어진 영역과 내부 빈 공간은 유지하고, 점·선으로만 닿는 비다양체 형상은 거부합니다.
  • 정확한 24개 직교 자세를 사용합니다. 반사하지 않습니다. 분말 지지의 Z 다단 배치를 허용합니다.
  • 벽 간격은 X·Y 네 측면에만 적용합니다. STEP 삼각화 오차 여유는 별도로 유지합니다. 모델 간격은 모든 방향에 적용합니다.
  • FCL·솔리드 포함·최소 거리·경계와 고리 얽힘 방지를 사용합니다. 최적성이나 모든 분리 경로를 증명하지는 않습니다.
  • CHITUBOX는 기존 0.01 mm 저장 수치 허용오차로 저장 좌표를 다시 검사합니다. 배치된 부품끼리는 불리언 합치기하지 않습니다.
  • 손상된 STL은 진단용 미리보기만 제공할 수 있으며 검증된 배치에는 사용하지 않습니다.

3. 내장 정책과 화면

제공된 정책은 학습 608회·갱신 12,825회·범위 157개이며 추가 학습·정책 파일 교체·저장을 제공하지 않습니다. 범위 밖에서는 기존 알고리즘으로 배치합니다. 원점·전체·각 축 보기와 마우스 회전·휠 확대를 제공합니다. 화면은 원본 표면 전체를 깊이 버퍼로 표시하여 얇은 벽과 내부 구멍을 올바르게 가립니다. 표시용 면 생략이나 형상 축약을 하지 않습니다. 빌드박스·원점·X/Y/Z축만 표시하며 격자와 숫자 눈금은 생략합니다. 3D 화면에는 OpenGL 그래픽 환경이 필요합니다. 표시 오류가 발생해도 계산·검증·저장 결과는 유지됩니다.

4. 저장·취소·한계

입력 조건·프로필·파일 경로·단위·수량·허용 자세는 사용자별 설정에 저장합니다. 재실행 시 파일을 자동으로 읽지 않으므로 파일 다시 읽기를 누르세요. 계산 중 중단하면 검증된 최선의 부분 결과를 반환합니다. 저장 중 중단은 파일 쓰기 정리가 끝날 때까지 기다립니다. 최초 입력 처리와 최종 검증·저장은 탐색 제한 시간과 별도입니다. Windows EXE 검증은 별도 네이티브 검사를 통해 확인해야 합니다.
