1. 제품 개요와 검사 범위

슬라이싱 위치 검사는 한 작업의 첫 층부터 마지막 층까지 연속된 이미지를 받아, 인접층에서 기존 연결 형상의 XY 위치 변화가 나타나는지 확인합니다. 교체한 첫 층을 알고 있으면 ‘치환 경계 검사’, 위치를 특정하지 않고 전체 흐름을 살피려면 ‘전체 스캔’을 사용합니다.

작업 목적선택할 기능결과
61층부터 교체한 뒤 60→61층을 확인치환 경계 검사 / 치환 시작 층 61해당 경계와 주변 이동 추이를 비교
전체 레이어에서 의심 위치 찾기전체 스캔모든 인접쌍의 분류와 의심 층 목록
모델의 회전·축척·소수 픽셀 이동 계측이 탭의 검사 범위에 포함되지 않음별도 검토 필요
확인 사항

인접층은 원래 단면이 달라질 수 있습니다. 이 탭의 결과는 위치 이동에 관한 참고 신호이며, 출력 적합성이나 실제 배치 불량을 확정하는 판정이 아닙니다. 같은 층의 교체 전·후 두 세트를 선택하는 GUI 기능은 제공하지 않습니다.

정수 픽셀 단위의 평행 이동만 탐색합니다. 연결된 흰 영역은 검사 기준점으로 취급하며, 하나의 연결 영역이 실제 제품 하나와 일치한다고 보장하지 않습니다. 새 형상이 추가되었다는 이유만으로 위치 불량으로 판정하지 않도록 기존 형상을 중심으로 비교합니다.

2. 빠른 시작 — 300층의 61층 교체 경계

다음은 사용 절차를 익히기 위한 예시입니다. 실제 XY 해상도가 400 DPI이고, 300층 중 61~300층을 교체했다고 가정합니다. 검사를 실행해도 입력 이미지는 변경되지 않습니다.

  1. 통합 프로그램에서 ‘슬라이싱 위치 검사’ 탭을 엽니다. 이 설명서는 탭 상단의 ‘사용설명서’ 버튼이나 메인 창의 F1로 다시 열 수 있습니다.
  2. ‘ZIP 파일 선택’으로 전체 스택 ZIP을 선택하거나, ‘이미지 전체 선택’에서 1.png~300.png를 모두 선택합니다.
  3. 검사 모드를 ‘치환 경계 검사’로 둡니다.
  4. ‘DPI’에 실제 해상도인 400을 입력합니다. ‘치환 시작 층’에 61을 입력합니다.
  5. ‘검사 시작’을 누르고 진행 로그를 확인합니다. 경계와 전후 최대 네 개씩의 인접쌍을 검사하며, 첫 층이나 마지막 층에 가까우면 가능한 쌍만 비교합니다.
  6. 완료되면 ‘보고서 보기’를 눌러 판정 근거를 읽습니다. 형상 번호나 ‘겹쳐 보기’ 링크를 열어 해당 부분을 확대합니다.
  7. ‘결과 폴더 열기’로 HTML, JSON, CSV와 이미지 파일이 함께 저장되었는지 확인합니다.
참고

치환 시작 층은 파일을 교체한 첫 실제 층입니다. 61~300층을 교체했다면 61을 입력하며, 마지막 교체 층 300이나 바로 앞 층 60을 입력하지 않습니다.

예시 B에서도 치환 시작 층에는 실제 층 번호 61을 입력합니다. 프로그램이 0 시작 파일 번호에 +1 보정을 적용합니다. layer_0001.png처럼 접두사가 있어도 마지막 숫자 그룹으로 층을 읽습니다. 서로 다른 하위 폴더에 같은 층 번호가 있으면 자동 번호 대응이 모호하므로 오류가 납니다.

EXIF 방향을 자동 회전하거나 이미지를 자동 리사이즈하지 않습니다. 고정 베드 좌표를 유지하는 것이 기준입니다. 투명 이미지는 검정 배경에 합성하며, 지원하는 16비트 정수 명도 이미지는 8비트 명도로 환산합니다. 부동소수점 파일이나 지원하지 않는 정수 범위는 오류로 안내합니다.

5. 검사 설정과 단위

사용자 입력초기값의미와 조건
DPI400실제 XY 해상도. 0보다 큰 유한한 숫자. 가로·세로 DPI가 같다는 전제
치환 시작 층612 이상의 정수이며 전체 입력 안에 있는 실제 교체 첫 층. 전체 스캔에서는 사용하지 않음

DPI는 1인치당 픽셀 수입니다. 한 픽셀의 길이는 25.4 / DPI mm로 환산합니다. 예를 들어 400 DPI에서는 0.0635 mm/px이고, 4픽셀 이동 후보는 0.254 mm입니다. DPI 값이 잘못되면 같은 픽셀 이동을 다른 mm 값으로 해석하므로 장비·슬라이서의 실제 XY 해상도를 확인합니다.

이 탭에서 사용하는 내부 기준값설명
기본 허용 이동량0.2 mm주변 이동 추이를 뺀 신호 등을 분류할 때 사용하는 기준
탐색 범위X/Y 각각 ±3.0 mm400 DPI에서는 축별 정수 탐색 한도 47픽셀
이진화 기준127명도가 127보다 큰 픽셀을 흰 재료로 처리
형상 최소 면적1 pixel기준 이미지의 연결 형상 선택 기준
최대 검사 형상512개초과로 제외된 형상이 있으면 완전 검증으로 간주하지 않음
추이 비교 문맥경계 전후 최대 4쌍연속 대응이 유지되는 형상별로 이동 흐름 추적
참고

위 내부 기준은 이 탭의 현재 고정값을 설명한 표입니다. 화면에서 허용량·탐색 범위·임계값을 수정하는 입력칸은 없습니다. 물리 탐색 범위가 ±512픽셀을 넘도록 지나치게 큰 DPI를 입력하면 검사를 거부합니다.

6. 치환 경계 검사 사용 방법

  1. 교체 전 부분과 교체 후 부분이 함께 들어 있는 완성 스택을 준비합니다. 교체한 구간만 따로 선택하지 않습니다.
  2. ‘치환 경계 검사’를 선택하고 교체한 첫 실제 층을 입력합니다.
  3. 검사를 실행해 대상 경계의 형상 번호 목록과 경계 이동 신호를 확인합니다.
  4. ‘형상 대응 불명확’, ‘주변 추이 부족’, ‘전후 흐름이 다름’과 같은 근거가 있는 형상은 해당 사유를 함께 검토합니다.
  5. 형상 번호를 눌러 경계 전후 픽셀을 확대하고, 같은 형상의 이전·이후 비교도 함께 읽습니다.

프로그램은 대상 경계에서 관찰한 이동만 보지 않고, 각 형상의 앞뒤 층에서 얻은 안정적인 이동 추이를 함께 사용합니다. 형상이 갈라지거나 합쳐지거나 대응이 모호하면 추적을 끊습니다. 한쪽에서만 안정적인 추이를 얻은 경우에는 그 사실을 결과 근거에 남깁니다. 큰 이동 후보가 보이더라도 신뢰할 만한 주변 추이가 부족하면 판단을 보류할 수 있습니다.

확인 사항

작업 시작·끝에 너무 가까운 경계는 주변 비교 자료가 부족할 수 있습니다. ‘신호 없음’과 ‘판단 보류’를 같은 뜻으로 읽지 않습니다. 제외되거나 대응을 확인하지 못한 형상이 남아 있으면 전체 형상이 확인된 결과가 아닙니다.

7. 전체 스캔 사용 방법

  1. 전체 스택을 선택하고 ‘전체 스캔’을 선택합니다. ‘치환 시작 층’ 입력칸이 비활성화되는 것을 확인합니다.
  2. 실제 DPI를 입력한 후 ‘검사 시작’을 누릅니다. N장의 입력이면 N−1개의 인접쌍을 검사합니다.
  3. 완료 보고서의 ‘어긋남 의심’, ‘신호 없음’, ‘판단 보류’ 수를 확인합니다.
  4. 의심 구간 목록에서 각 경계의 겹쳐 보기를 먼저 확인합니다.
  5. 필요하면 ‘전체 인접층 비교 …개 펼치기’와 형상 목록을 열어 의심으로 분류되지 않은 구간의 근거도 확인합니다.

예를 들어 1,820장의 이미지를 넣으면 1→2층부터 1,819→1,820층까지 총 1,819쌍을 검사합니다. 전체 스캔에서도 각 경계를 주변 형상 추이와 비교합니다. 단순히 전체 흰 픽셀 수가 증가했다는 이유로 위치 이동으로 분류하지 않습니다. 형상 추가·단면 변화·접촉·잘림은 대응을 어렵게 할 수 있습니다.

해상도가 큰 입력은 압축 파일의 크기보다 디코딩한 픽셀 수의 영향을 많이 받습니다. 비교 데이터·원본 해상도의 PNG·형상별 뷰어를 함께 생성하므로 완료까지 기다린 뒤 결과를 사용합니다. 캐시와 비트 연산은 처리 시간을 줄이지만 픽셀을 축소하거나 판정 근거를 생략하지 않습니다.

8. 판정과 수치를 읽는 방법

보고서 분류의미확인할 작업
어긋남 의심 신호주변의 통상 이동과 다른 변화가 허용량을 넘는 형상 신호가 있음해당 형상·경계와 비교 근거 확대 확인
뚜렷한 이동 신호 없음검사 가능한 형상에서 기준을 넘는 경계 신호를 찾지 못함검증 형상 수와 제외·보류 여부 확인
판단 보류 / 확인 필요형상 대응이나 안정적인 주변 추이가 부족함모양 변화·반복 형상·잘림·빈 이미지 등 사유 확인
수치/용어읽는 방법
dx / dy pixels오른쪽이 +dx, 아래쪽이 +dy. 정수 픽셀 이동 후보
dx / dy mm해당 DPI로 환산한 축별 물리 이동량
distance_mmXY 벡터의 거리. 단면 변화와 구별된 확정 불량량을 항상 뜻하지는 않음
경계 이동 신호주변 추이 보정을 적용해 비교한 이동 신호
검증 형상 수고유하고 신뢰할 만한 대응을 확인한 연결 형상 수
부분 검증 / 제외 형상일부 형상만 확인했거나 검사 개수 제한 등으로 제외되었음을 나타냄

반복되는 같은 모양이 여러 위치에 있으면 어느 형상을 어느 위치와 대응해야 하는지 확정하기 어렵습니다. 검색 한도에 걸린 최적 후보, 같은 점수의 여러 위치, 큰 형상 변화, 이미지 크기 불일치, 빈 이미지도 보류 근거가 됩니다. 낮은 점수의 후보가 표시되어도 그 후보를 곧바로 확인된 이동으로 해석하지 않습니다.

9. 겹쳐 보기와 형상 번호

표시 색상뜻
검정두 이미지 모두 배경
빨강이전 층에만 재료가 있는 픽셀
청록현재 층에만 재료가 있는 픽셀
흰색두 층의 재료가 겹치는 픽셀
노랑 선과 끝점검출 목록 앞 30개 중 대응이 확인되고 이동이 0이 아닌 형상의 이동 방향. 모든 검사 형상에 표시되는 것은 아님
  1. 보고서에서 ‘겹쳐 보기’ 링크나 형상 번호를 눌러 별도 뷰어를 엽니다.
  2. 파란 번호나 표의 번호를 선택하면 해당 연결 형상 주변으로 화면이 이동·확대됩니다.
  3. 마우스 휠 또는 +/− 버튼으로 확대·축소하고, 화면을 드래그해 주변으로 이동합니다.
  4. 전체 보기 버튼으로 초기 범위로 돌아갑니다. 키보드로 형상 링크를 선택한 뒤 Enter 또는 Space로 활성화할 수도 있습니다.

형상 번호는 바로 앞 층의 2D 연결 영역 번호입니다. 다른 경계의 같은 번호가 같은 3D 모델을 의미하지는 않습니다. 그림은 원본 해상도의 픽셀 격자에 겹침 색과 이동 선·끝점을 표시합니다. PNG는 다섯 색의 무손실 팔레트 형식으로 저장되며, 파일 내부 P 모드와 화면 표시 RGB 색상은 구분합니다. 표시 개수 제한으로 이동 선이 없어도 이동 후보가 없다는 뜻은 아니므로 형상별 표와 수치를 함께 확인합니다.

10. 사용 예시 — 이동과 형상 추가

예시 1. 경계에서 오른쪽으로 4픽셀 이동

400 DPI의 300층에서 61층부터 같은 기존 형상이 오른쪽으로 4픽셀 이동했고, 경계 전후의 통상 이동은 0이라고 가정합니다. 전체 300장을 선택하고 경계 61을 검사합니다. 고유한 형상 대응과 안정적인 주변 추이를 확보하면 4 × 25.4 / 400 = 0.254 mm의 경계 이동 신호가 기본 기준 0.2 mm를 넘는 사례가 됩니다. 반복 형상이나 잘림 등으로 대응이 불명확하면 이와 같은 수치 조건만으로 의심 분류를 확정하지 않습니다.

예시 2. 1,601층에 새 형상만 추가

1,820층 중 1,601층에서 흰 재료 면적이 크게 증가했지만 기존 형상의 위치는 그대로인 상황입니다. 전체 스캔으로 전체 흐름을 보고 1,600→1,601층을 확대합니다. 새 형상이 추가되었다는 사실만으로 위치 어긋남으로 분류하지 않습니다. 기존 형상에 대한 대응이 유지되고 이동 신호가 없으면 ‘신호 없음’으로 남을 수 있으며, 새 형상과 기존 형상이 붙어 대응이 바뀌면 보류될 수 있습니다.

예시 3. 번호가 빠진 스택

1.png~300.png 중 125.png가 없다면 빈 층을 임의로 삽입하거나 번호를 당겨 맞추지 않습니다. 전체 번호 검사가 중간 층 누락을 알려 줍니다. 원본 슬라이서에서 해당 층을 다시 내보낸 뒤, 전체 스택을 다시 선택합니다.

이미지 목록을 선택하면 첫 선택 파일의 부모 폴더, ZIP을 선택하면 ZIP의 부모 폴더 아래에 보고서를 저장합니다. 매번 시각이 포함된 새 검사 폴더를 만듭니다. 보고서를 전달하거나 보관할 때는 report.html만 따로 복사하지 말고 해당 check_… 폴더 전체를 함께 보관해야 상대 경로의 이미지와 뷰어가 열립니다.

12. 중단·재실행과 통합 프로그램 종료

  1. 중단하려면 탭 안의 ‘검사 중지’ 또는 통합 창 상단의 ‘현재 작업 중단’을 누릅니다.
  2. 현재 이미지 처리·비교 단계가 끝날 때까지 기다립니다. 버튼을 누른 즉시 이미 진행 중인 연산을 강제로 종료하지는 않습니다.
  3. ‘검사를 중지했습니다’와 미완료 안내를 확인합니다. 다시 실행할 때는 입력·모드·DPI·치환 시작 층을 재확인합니다.
  4. 통합 창을 닫으면 진행 중 작업의 중단 확인 후 정리를 기다립니다. 작업 중에는 프로세스를 강제로 종료하는 대신 정상 중단 절차를 사용합니다.

중단된 작업의 남은 구간부터 자동 재개하는 기능은 없습니다. 재실행하면 새 검사 폴더에 처음부터 수행합니다. 보고서의 완료 상태를 확인한 뒤, 필요 없는 미완료 폴더는 운영자가 정리할 수 있습니다.

15. 입력값 자동 저장과 복원

통합 프로그램을 정상 종료하면 입력값을 사용자별로 저장합니다. 다음 실행에서 이 도구를 열 때 저장한 값을 복원하며, 열지 않은 탭의 이전 설정도 유지합니다. 계산이나 파일 처리를 자동으로 시작하지 않습니다.

  • 저장 대상: 입력 숫자·문자·선택·체크 상태·원본 경로·입력 목록과 작업에 필요한 배치·프로파일. 이미지 변환의 사용자 픽셀·DPI와 오븐의 언어·불러온 열전대 수치도 포함합니다.
  • 계산 결과·로그·진행 중 작업·이미지와 메쉬 원본은 설정에 저장하지 않습니다. 결과는 필요한 CSV·JSON·HTML·STL 등으로 따로 저장합니다.
  • 저장 위치: Windows는 %LOCALAPPDATA%\BJT_Tools\settings.json. Linux는 $XDG_CONFIG_HOME/BJT_Tools/settings.json 또는 ~/.config/BJT_Tools/settings.json입니다.
  • 원본이나 변환 캐시를 이동·삭제하면 복원한 경로를 사용할 수 없을 수 있습니다. 복원된 입력과 실제 파일을 확인한 뒤 실행합니다.
  • 강제 종료·프로세스 종료·전원 차단 직전의 변경은 정상 종료 저장에 포함되지 않을 수 있습니다. 저장 실패 시 경고·오류 기록을 확인하고 기존 설정을 보존합니다.
참고

손상된 설정은 기본값으로 시작하며, 다음 저장 시 손상 파일을 settings.json.corrupt-시각 이름으로 보관합니다. 복원할 수 없는 숫자형 항목은 기본값을 사용할 수 있으므로 실행 전 입력을 확인하세요.
